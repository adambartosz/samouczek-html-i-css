Co to jest CSS?

CSS (Cascading Style Sheets) to język służący do opisywania wyglądu elementów HTML. Dzięki niemu można zmieniać kolory, rozmiary, odstępy, położenie elementów oraz sposób ich wyświetlania.

HTML odpowiada za strukturę strony, natomiast CSS za jej wygląd. Bez CSS większość stron internetowych wyglądałaby bardzo prosto i mało atrakcyjnie.

Przeglądarka najpierw odczytuje dokument HTML, a następnie stosuje do niego reguły zapisane w arkuszach stylów.

Po co używa się CSS?

Najważniejsze zastosowania CSS:

  • zmiana kolorów tekstu i tła
  • ustalanie rozmiarów elementów
  • tworzenie układów stron
  • ustawianie marginesów i odstępów
  • dodawanie animacji i efektów przejść
  • dostosowywanie strony do telefonów i tabletów
  • oddzielenie wyglądu od struktury HTML

Dzięki temu sam kod HTML jest prostszy i bardziej czytelny.

Sposoby dodawania CSS

Style można dodawać na trzy podstawowe sposoby.

1. Styl lokalny

Reguła znajduje się bezpośrednio w znaczniku HTML.

<p style="color:red;">Czerwony tekst</p>

Ten sposób jest prosty, ale przy większych projektach niewygodny.

2. Styl wewnętrzny

<style>

p {

    color: red;

}

</style>

Reguły zapisuje się w sekcji <head>.

3. Zewnętrzny arkusz stylów

<link rel="stylesheet" href="style.css">

To najczęściej używane rozwiązanie. Wszystkie style znajdują się w osobnym pliku CSS.

Budowa reguły CSS

Każda reguła składa się z selektora oraz deklaracji.

p {

    color: blue;

    font-size: 20px;

}

W tym przykładzie:

  • p - selektor
  • color - właściwość
  • blue - wartość właściwości
  • font-size - kolejna właściwość
  • 20px - wartość tej właściwości

Jedna reguła może zawierać wiele właściwości.

Najpopularniejsze selektory

Selektor Przykład Działanie
Znacznik p Wybiera wszystkie akapity
Klasa .menu Wybiera elementy z klasą menu
Id #naglowek Wybiera element o podanym identyfikatorze
* * Wybiera wszystkie elementy
Potomek nav a Linki znajdujące się w nav

Selektory określają, które elementy HTML mają otrzymać dany styl.

Jednostka Znaczenie

Najczęściej początkujący używają jednostki px, ale warto znać również pozostałe.

Kaskadowość stylów

Słowo Cascading oznacza kaskadowość. Jeżeli kilka reguł dotyczy tego samego elementu, przeglądarka musi zdecydować, która ma zostać użyta.

Przykład:

p {

    color: blue;

}



p {

    color: red;

}

Tekst będzie czerwony, ponieważ druga reguła znajduje się niżej.

Na wynik wpływają również:

  • kolejność reguł
  • specyficzność selektorów
  • użycie !important

Przykład kompletnej strony

<!DOCTYPE html>

<html lang="pl">

<head>

    <meta charset="utf-8">

    <title>Przykład</title>

    <link rel="stylesheet" href="style.css">

</head>

<body>

    <h1>Witaj świecie!</h1>

    <p>To jest przykładowa strona.</p>

</body>

</html>

Plik CSS:

body {

    font-family: Arial, sans-serif;

}



h1 {

    color: navy;

}



p {

    color: gray;

}

Dobre praktyki

  • stosuj zewnętrzne arkusze stylów
  • nazywaj klasy w sposób zrozumiały
  • unikaj nadmiernego używania id
  • dbaj o czytelne wcięcia kodu
  • grupuj podobne reguły razem
  • nie używaj zbyt wielu stylów lokalnych
  • testuj stronę na różnych urządzeniach
  • kompresuj i porządkuj CSS przy większych projektach
