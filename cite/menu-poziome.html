Co to jest menu poziome?

Menu poziome to pasek nawigacyjny, w którym linki są ułożone obok siebie w jednej linii. To najczęstszy sposób nawigacji na stronach internetowych – zwykle siedzi na górze strony.

Buduje się je ze znacznika <nav> z listą <ul> i elementami <li>, w których siedzą linki <a>. Lista jest domyślnie pionowa, więc CSS musi ją "położyć" poziomo.

Struktura HTML

Prawidłowa semantycznie struktura menu:

<nav>

  <ul>

    <li><a href="index.html">Strona główna</a></li>

    <li><a href="o-nas.html">O nas</a></li>

    <li><a href="oferta.html">Oferta</a></li>

    <li><a href="kontakt.html">Kontakt</a></li>

  </ul>

</nav>

Używamy <nav> bo to semantyczny znacznik nawigacji – czytniki ekranu i Google wiedzą, że to menu. Lista <ul> ma sens, bo menu to zbiór równorzędnych pozycji.

CSS – układamy poziomo

Mamy dwa popularne sposoby na ułożenie listy poziomo.

Sposób 1: Flexbox – najprostszy i najpopularniejszy:

nav ul {

  list-style: none;

  margin: 0;

  padding: 0;

  display: flex;

  gap: 8px;

}



nav ul li a {

  display: block;

  padding: 10px 18px;

  text-decoration: none;

  color: white;

  background: #333;

  border-radius: 4px;

}



nav ul li a:hover {

  background: #555;

}

Sposób 2: display inline-block – starszy, ale działa wszędzie:

nav ul {

  list-style: none;

  margin: 0;

  padding: 0;

}



nav ul li {

  display: inline-block;

}



nav ul li a {

  display: inline-block;

  padding: 10px 18px;

  text-decoration: none;

  color: white;

  background: #333;

}



nav ul li a:hover {

  background: #555;

}

Kluczowe rzeczy w obu sposobach:

  • list-style: none – usuwa kropki z listy
  • margin: 0; padding: 0 – usuwa domyślne wcięcia listy
  • display: block na linku – link wypełnia cały obszar li, więc cały kafelek jest klikalny
  • text-decoration: none – usuwa podkreślenie linku

Aktywna pozycja menu

Zazwyczaj chcemy wyróżnić stronę, na której aktualnie jesteśmy. Robi się to przez klasę active na odpowiednim <li> lub <a>:

<li><a href="index.html" class="active">Strona główna</a></li>
nav ul li a.active {

  background: #0066cc;

  color: white;

}

Wyrównanie menu

Dzięki Flexboxowi na kontenerze nav lub ul możesz łatwo sterować położeniem linków:

Menu wyśrodkowane:

nav ul {

  display: flex;

  justify-content: center;

}

Menu po prawej:

nav ul {

  display: flex;

  justify-content: flex-end;

}

Menu rozciągnięte na całą szerokość (każdy link zajmuje tyle samo miejsca):

nav ul {

  display: flex;

}



nav ul li {

  flex: 1;

}



nav ul li a {

  display: block;

  text-align: center;

}

Menu z logo po lewej i linkami po prawej:

nav {

  display: flex;

  justify-content: space-between;

  align-items: center;

}



nav ul {

  display: flex;

  gap: 8px;

}
