Czym są selektory?

Selektory CSS określają, które elementy HTML mają otrzymać dane style. Są one pierwszą częścią każdej reguły CSS.

Przykład:

p {

    color: blue;

}

W tym przypadku selektorem jest p, a styl zostanie zastosowany do wszystkich akapitów na stronie.

Bez selektorów przeglądarka nie wiedziałaby, do których elementów przypisać konkretne właściwości CSS.

Selektor typu (znacznika)

Selektor typu wybiera wszystkie elementy o podanej nazwie znacznika.

Przykład dla akapitów:

p {

    color: red;

}

Wszystkie znaczniki <p> otrzymają czerwony kolor tekstu.

Przykład dla nagłówków:

h1 {

    text-align: center;

}

Każdy nagłówek <h1> zostanie wyśrodkowany.

Można używać dowolnych znaczników HTML jako selektorów:

  • body
  • div
  • p
  • h1
  • img
  • table
  • a
  • button

Selektor grupowy

Selektor grupowy pozwala przypisać te same style do wielu różnych elementów jednocześnie.

Poszczególne selektory oddziela się przecinkami.

h1, h2, h3 {

    color: navy;

}

Wszystkie nagłówki h1, h2 i h3 otrzymają ten sam kolor.

Kolejny przykład:

p, li, td {

    font-size: 18px;

}

Akapity, elementy list i komórki tabel będą miały taki sam rozmiar tekstu.

Dzięki grupowaniu można znacząco skrócić kod CSS.

Porównanie selektorów

Selektor Przykład Działanie
Typu p Wybiera wszystkie akapity
Typu img Wybiera wszystkie obrazki
Typu table Wybiera wszystkie tabele
Grupowy h1, h2, h3 Wybiera kilka typów elementów jednocześnie
Grupowy p, li, a Styl dla różnych elementów naraz

Zalety selektorów grupowych

  • mniej powtarzającego się kodu
  • łatwiejsza edycja stylów
  • czytelniejszy arkusz CSS
  • szybsze wprowadzanie zmian
  • mniejsze ryzyko pomyłek

Zamiast pisać:

h1 {

    color: blue;

}



h2 {

    color: blue;

}



h3 {

    color: blue;

}

Można napisać:

h1, h2, h3 {

    color: blue;

}

Efekt będzie identyczny, ale kod będzie krótszy.
