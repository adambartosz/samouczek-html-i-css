Właściwość background-image służy do ustawiania obrazka jako tła elementu w CSS. Dzięki niej można zrobić tło strony albo konkretnego bloku.

Obrazek jest wyświetlany „pod” treścią elementu, a nie zamiast niej.

Najczęściej używa się plików JPG i PNG.

Składnia: background-image: url("ścieżka");

Wartość Co robi
url("plik.jpg") wstawia obrazek jako tło
none brak tła obrazkowego
inherit dziedziczy tło od rodzica
initial usuwa tło (ustawia domyślne)

Domyślnie background-image ma wartość none, czyli brak obrazka.

Jeśli nie ustawimy tej właściwości, element ma tylko zwykłe tło kolorowe lub przezroczyste.

inherit powoduje przejęcie tła od rodzica, a initial je resetuje.

Ta właściwość nie zmienia rozmiaru elementu – tylko jego tło.

Obrazek może się powtarzać domyślnie, jeśli nie ustawimy background-repeat.

div {
    background-image: url("img/tlo.jpg");
}

Można też ustawić brak powtarzania:

div {
    background-image: url("img/tlo.jpg");
    background-repeat: no-repeat;
}

Przykłady użycia:

body {
    background-image: url("img/tlo.jpg");
}
.box {
    background-image: url("img/kot.png");
}
header {
    background-image: url("img/banner.jpg");
}

Najczęściej tło ustawia się na całej stronie albo w nagłówku.

Symulator: wybierz obrazek tła i zobacz efekt na elemencie.
