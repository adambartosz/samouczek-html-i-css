Selektor uniwersalny

Selektor * wybiera wszystkie elementy znajdujące się w dokumencie.

Najczęściej spotyka się go w arkuszach zerujących oraz przy ustawianiu wspólnych właściwości dla całej strony.

* {

    box-sizing: border-box;

}

Łączenie selektorów

Można wskazać element, który jednocześnie spełnia kilka warunków.

p.uwaga {

    color: red;

}

Ten selektor wybierze tylko znaczniki p posiadające klasę uwaga.

a.zewnetrzny {

    font-weight: bold;

}

Zwykłe linki bez tej klasy nie zostaną wybrane.

Wiele klas jednocześnie

Element może posiadać kilka klas naraz.

.przycisk.duzy {

    padding: 20px;

}

Przeglądarka wybierze tylko elementy posiadające jednocześnie klasę przycisk oraz duzy. 

<button class="przycisk duzy">

    Kliknij

</button>

Selektor :root

Pseudoklasa :root wskazuje główny element dokumentu.

W HTML jest nim znacznik html.

:root {

    --kolor-glowny: blue;

}

Najczęściej używa się jej podczas tworzenia własnych zmiennych CSS.

Selektor :target

Wybiera element, do którego prowadzi aktualny adres URL z kotwicą.

#kontakt:target {

    border: 2px solid red;

}

Jeżeli użytkownik przejdzie pod adres:

strona.html#kontakt

Element o identyfikatorze kontakt zostanie wybrany.

Selektor :lang()

Pozwala wybierać elementy zapisane w określonym języku.

p:lang(pl) {

    font-style: italic;

}

Zadziała tylko dla elementów oznaczonych jako język polski.

<p lang="pl">Tekst</p>

Selektor :has()

Jest jednym z najnowszych i najpotężniejszych selektorów CSS.

Pozwala wybierać element na podstawie tego, co znajduje się w jego wnętrzu.

div:has(img) {

    border: 2px solid green;

}

Zostaną wybrane tylko elementy div, które zawierają obrazek.

Selektor :scope

Odnosi się do aktualnego punktu odniesienia podczas wyszukiwania elementów.

:scope > p {

    color: blue;

}

Najczęściej spotyka się go podczas pracy z JavaScriptem.

Selektory formularzy

CSS posiada wiele specjalnych selektorów przeznaczonych dla formularzy.

Selektor Działanie
:checked Zaznaczony checkbox lub radio
:disabled Wyłączone pole formularza
:enabled Aktywne pole formularza
:required Pole wymagane
:optional Pole niewymagane
:valid Poprawnie wypełnione pole
:invalid Niepoprawnie wypełnione pole
:in-range Wartość znajduje się w zakresie
:out-of-range Wartość poza zakresem
:read-only Pole tylko do odczytu
:read-write Pole możliwe do edycji

Selektory logiczne

Nowoczesny CSS pozwala tworzyć bardziej zaawansowane warunki.

:is(header, main, footer) {

    padding: 20px;

}

Można grupować wiele selektorów.

:where(nav ul li a) {

    text-decoration: none;

}

Można także tworzyć bardzo rozbudowane zależności bez zwiększania specyficzności.
