Właściwość border służy do ustawiania obramowania elementu w CSS. Dzięki niej możemy kontrolować grubość, styl i kolor ramki wokół elementu.

Border jest częścią modelu pudełkowego i znajduje się między paddingiem a marginesem.

Może być prosty albo bardzo rozbudowany wizualnie, np. przerywany, podwójny albo zaokrąglony.

Składnia: border: szerokość styl kolor;

Wartość Co robi
solid ciągła linia
dashed przerywana linia
dotted kropkowana linia
double podwójna linia
none brak obramowania
hidden ukryte obramowanie (różni się od none w tabelach)

Domyślna wartość to brak obramowania, czyli none.

Jeśli nie ustawimy border, element nie ma widocznej ramki.

Wartość initial usuwa obramowanie, a inherit pobiera je od elementu rodzica.

Właściwość border nie jest dziedziczona automatycznie.

Jeśli ustawimy ramkę dla rodzica, dzieci jej nie przejmują.

div {
    border: 2px solid black;
}

Aby wymusić dziedziczenie, trzeba użyć:

p {
    border: inherit;
}

Przykłady użycia:

Prosta ramka:

div {
    border: 1px solid black;
}

Przerywana ramka:

div {
    border: 2px dashed red;
}

Podwójna ramka:

div {
    border: 4px double blue;
}

Brak ramki:

div {
    border: none;
}
