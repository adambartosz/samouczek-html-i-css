Właściwość text-decoration służy do dekorowania tekstu liniami. Najczęściej używa się jej do podkreślenia, przekreślenia albo nadkreślenia tekstu.

Można nią też ustawiać styl linii, jej grubość i kolor. Jest często używana przy linkach i wyróżnieniach.

Działa na tekst, ale nie zmienia jego treści ani struktury HTML.

Składnia: text-decoration: wartość;

Wartość Co robi
none Usuwa dekorację tekstu
underline Dodaje linię pod tekstem
overline Dodaje linię nad tekstem
line-through Przekreśla tekst
underline overline Łączy dwie linie: pod i nad tekstem
underline line-through Podkreślenie i przekreślenie jednocześnie
solid Linia ciągła
dashed Linia przerywana
dotted Linia kropkowana
double Podwójna linia
wavy Linia falowana
inherit Dziedziczy wartość od rodzica
initial Przywraca wartość domyślną
unset Jak inherit lub initial zależnie od kontekstu
revert Przywraca styl przeglądarki

Domyślna wartość to none, czyli brak dekoracji tekstu.

Jeżeli nie ustawimy tej właściwości, tekst będzie wyświetlany normalnie bez linii.

Wartość initial również przywraca brak dekoracji, a inherit przejmuje ustawienia od elementu nadrzędnego.

Właściwość text-decoration jest dziedziczona tylko częściowo. W praktyce często zachowanie zależy od konkretnej przeglądarki i wartości.

Jeśli ustawimy dekorację dla elementu nadrzędnego, elementy potomne mogą ją odziedziczyć, ale można to nadpisać.

a {

    text-decoration: underline;

}

Wartości inherit i initial pozwalają kontrolować to zachowanie.

Przykłady użycia:

Podkreślone linki:

a {

    text-decoration: underline;

}

Usunięcie podkreślenia:

a {

    text-decoration: none;

}

Przekreślony tekst:

.stare {

    text-decoration: line-through;

}

Funkcja dekoracyjna:

h1 {

    text-decoration: overline;

}

Stylowana linia:

p {

    text-decoration: underline wavy red;

}
