Właściwość font-family służy do określenia, jaką czcionką ma być wyświetlany tekst na stronie internetowej. Jest jedną z najczęściej używanych właściwości związanych z typografią. Możemy podać jedną czcionkę albo całą listę zapasowych czcionek używanych wtedy, gdy poprzednia nie jest dostępna.

Dzięki tej właściwości możemy wpływać na wygląd nagłówków, akapitów, menu i wszystkich innych elementów zawierających tekst.

Składnia: font-family: wartość;

Najczęściej podaje się kilka czcionek oddzielonych przecinkami:

font-family: Arial, Helvetica, sans-serif;
Wartość Co robi
nazwa konkretnej czcionki Używa wskazanej czcionki, np. Arial, Verdana, Roboto, Georgia
serif Rodzina czcionek z ozdobnymi zakończeniami liter
sans-serif Rodzina czcionek bez ozdobników, bardzo popularna w internecie
monospace Każdy znak ma tę samą szerokość
cursive Czcionki przypominające pismo odręczne
fantasy Czcionki dekoracyjne i ozdobne
system-ui Używa domyślnej czcionki systemu operacyjnego
inherit Przejmuje wartość od elementu nadrzędnego
initial Przywraca wartość początkową właściwości
unset Zachowuje się jak inherit albo initial w zależności od typu właściwości
revert Przywraca wartość wynikającą z arkusza stylów przeglądarki
revert-layer Przywraca wartość z wcześniejszej warstwy CSS

Domyślna wartość właściwości to zależna od przeglądarki i systemu rodzina czcionek. Jeśli nie ustawimy font-family, tekst zostanie wyświetlony przy użyciu domyślnej czcionki użytkownika.

Wartość initial przywraca wartość początkową określoną przez specyfikację CSS. W praktyce często będzie to domyślna czcionka przeglądarki.

Wartość inherit powoduje przejęcie ustawienia od elementu nadrzędnego.

font-family: initial;
font-family: inherit;

Właściwość font-family jest dziedziczona. Oznacza to, że jeśli ustawimy ją dla elementu nadrzędnego, jego potomkowie zwykle również będą korzystać z tej samej czcionki.

Przykładowo ustawienie czcionki dla znacznika body spowoduje, że większość elementów na stronie odziedziczy tę wartość automatycznie.

body {

    font-family: Arial, sans-serif;

}

Wartość inherit wymusza dziedziczenie nawet wtedy, gdy element ma własne ustawienia. Wartość initial usuwa dziedziczenie i przywraca wartość początkową.

Ustawienie podstawowej czcionki dla całej strony:

body {

    font-family: Arial, sans-serif;

}

Użycie klasycznej czcionki szeryfowej w artykule:

article {

    font-family: Georgia, serif;

}

Użycie czcionki programistycznej dla kodu:

code {

    font-family: Consolas, monospace;

}

Użycie czcionki pobranej z Google Fonts:

body {

    font-family: "Roboto", sans-serif;

}
