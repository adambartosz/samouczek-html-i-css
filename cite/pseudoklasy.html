Co to są pseudoklasy?

Pseudoklasy CSS pozwalają wybierać elementy znajdujące się w określonym stanie lub położeniu. Nie wymagają dodawania dodatkowych klas w HTML.

Rozpoznaje się je po znaku : umieszczonym przed nazwą pseudoklasy. Dzięki nim można reagować na działania użytkownika lub wybierać elementy według ich pozycji w dokumencie.

Pseudoklasy są bardzo często używane przy linkach, formularzach, przyciskach i listach.

Składnia pseudoklas

Pseudoklasę dopisuje się na końcu selektora.

a:hover {

    color: red;

}

W tym przykładzie styl zostanie zastosowany po najechaniu kursorem na link.

Można również używać pseudoklas z innymi selektorami:

input:focus {

    border: 2px solid blue;

}
li:first-child {

    font-weight: bold;

}

Najpopularniejsze pseudoklasy

Pseudoklasa Działanie
:hover Element pod kursorem myszy
:active Element podczas kliknięcia
:focus Element posiadający fokus
:visited Odwiedzony link
:link Nieodwiedzony link
:checked Zaznaczony checkbox lub radio
:disabled Wyłączony element formularza
:enabled Aktywny element formularza
:required Pole wymagane
:optional Pole niewymagane
:first-child Pierwszy element w rodzicu
:last-child Ostatni element w rodzicu
:nth-child() Element o określonej pozycji
:empty Element bez zawartości

Pseudoklasy związane z użytkownikiem

Najczęściej spotykane pseudoklasy reagują na działania użytkownika.

Najechanie kursorem:

button:hover {

    background-color: lightblue;

}

Kliknięcie:

button:active {

    transform: scale(0.95);

}

Przejście do pola formularza:

input:focus {

    outline: 2px solid blue;

}

Zaznaczony checkbox:

input:checked {

    width: 25px;

}

Pseudoklasy pozycyjne

Niektóre pseudoklasy wybierają elementy na podstawie ich położenia w kodzie HTML.

Pierwszy element:

li:first-child {

    font-weight: bold;

}

Ostatni element:

li:last-child {

    color: red;

}

Trzeci element:

li:nth-child(3) {

    background: yellow;

}

Elementy parzyste:

tr:nth-child(even) {

    background: #eee;

}

Elementy nieparzyste:

tr:nth-child(odd) {

    background: #ddd;

}
