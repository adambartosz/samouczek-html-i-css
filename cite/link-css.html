Znacznik <link> służy do podłączania zewnętrznych zasobów do dokumentu HTML. Najczęściej używa się go do dołączania arkuszy CSS za pomocą atrybutu rel="stylesheet".

Jest elementem pustym, więc nie posiada zawartości ani znacznika zamykającego.

Najczęściej znajduje się w sekcji <head> strony.

Używamy go kiedy chcemy:

  • podłączyć zewnętrzny arkusz stylów CSS
  • załadować ikonę strony favicon
  • połączyć dokument z innym zasobem
  • przyspieszyć ładowanie niektórych zasobów przez preload
  • zdefiniować relacje pomiędzy dokumentami

Jeżeli chcemy osadzić kod CSS bezpośrednio w pliku HTML, zamiast <link> można użyć znacznika <style>.

Bardzo często za pomocą <link rel="stylesheet"> podłącza się również tak zwany arkusz zerujący Meyera (Meyer Reset CSS). Jego zadaniem jest usunięcie domyślnych marginesów, odstępów i stylów dodawanych przez przeglądarki, dzięki czemu strona wygląda bardziej przewidywalnie na różnych urządzeniach. 

<link rel="stylesheet" href="../css/arkuszzerujacy.css">

<link rel="stylesheet" href="../css/style.css">

Najpierw ładowany jest arkusz zerujący, a dopiero później właściwy plik ze stylami strony. Dzięki temu własne reguły CSS nadpisują ustawienia resetu.

Atrybut Wartości Co robi
href adres URL lub ścieżka Wskazuje położenie zasobu
rel stylesheet Informuje przeglądarkę, że podłączany plik jest arkuszem stylów CSS (np. style.css lub arkusz zerujący Meyera)
media all, screen, print i zapytania media Określa kiedy zasób ma być używany
sizes np. 16x16, 32x32, 180x180 Rozmiar ikony
imagesizes wartości atrybutu sizes Rozmiary obrazów dla niektórych relacji
imagesrcset lista obrazów srcset Alternatywne wersje obrazów
crossorigin anonymous, use-credentials Kontrola żądań między domenami
integrity hash SRI Sprawdza integralność pliku
referrerpolicy no-referrer, origin, strict-origin i inne Kontroluje nagłówek Referer
blocking render Wpływa na blokowanie renderowania
fetchpriority high, low, auto Priorytet pobierania zasobu
disabled disabled Wyłącza arkusz stylów
as style, script, font, image, fetch i inne Typ pobieranego zasobu przy preload
type typ MIME, np. text/css Typ zasobu
hreflang kod języka Język powiązanego zasobu
title tekst Nazwa alternatywnego arkusza stylów

Znacznik <link> ma znaczenie semantyczne, ponieważ informuje przeglądarkę o relacji pomiędzy bieżącym dokumentem a zewnętrznym zasobem.

Czytniki ekranu zwykle nie odczytują go użytkownikowi, ale przeglądarka wykorzystuje jego informacje do ładowania stylów, ikon i innych plików.

Roboty wyszukiwarek również mogą korzystać z informacji zapisanych w atrybucie rel.

Właściwość Wartość
Typ elementu Pusty
Znacznik zamykający Nie (niekontenerowy)
Semantyka Określa relację dokumentu z zewnętrznym zasobem
Może zawierać Żadnych elementów ani tekstu
Może być wewnątrz Najczęściej head, w wybranych przypadkach body
Domyślny display none
