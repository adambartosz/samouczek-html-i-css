Co to są pseudoelementy?

Pseudoelementy CSS pozwalają stylować fragment elementu lub tworzyć dodatkową zawartość bez dodawania nowych znaczników HTML.

Rozpoznaje się je po podwójnym dwukropku ::. Przeglądarka traktuje je jak specjalne części elementu.

Dzięki pseudoelementom można dodawać tekst, ozdobniki, zmieniać wygląd pierwszej litery lub zaznaczonego tekstu.

Składnia pseudoelementów

Pseudoelement dopisuje się na końcu selektora.

p::first-letter {

    font-size: 200%;

}

W tym przykładzie pierwsza litera każdego akapitu będzie większa od pozostałych.

Przykład dodawania treści:

.uwaga::before {

    content: "Uwaga: ";

}

Przeglądarka doda wskazany tekst przed zawartością elementu.

Najpopularniejsze pseudoelementy

Pseudoelement Działanie
::before Dodaje zawartość przed elementem
::after Dodaje zawartość za elementem
::first-letter Wybiera pierwszą literę
::first-line Wybiera pierwszy wiersz tekstu
::selection Styluje zaznaczony tekst
::marker Styluje punktory list
::placeholder Styluje tekst podpowiedzi w formularzu
::file-selector-button Styluje przycisk pola typu file

Pseudoelementy before i after

Są to najczęściej używane pseudoelementy.

Dodanie tekstu przed elementem:

.info::before {

    content: "[INFO] ";

}

Dodanie tekstu po elemencie:

.nowosc::after {

    content: " NOWOŚĆ";

}

Pseudoelementy te często wykorzystuje się do ikon, etykiet, dekoracji i efektów wizualnych.

Aby działały poprawnie, zwykle trzeba ustawić właściwość content.

Pozostałe przydatne pseudoelementy

Pierwsza litera akapitu:

p::first-letter {

    font-size: 32px;

}

Pierwsza linia tekstu:

p::first-line {

    font-weight: bold;

}

Tekst podpowiedzi formularza:

input::placeholder {

    color: gray;

}
