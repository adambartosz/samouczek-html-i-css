Właściwość overflow w CSS decyduje o tym, co się dzieje z treścią, która nie mieści się w elemencie.

Może ją ukryć, pokazać albo dodać paski przewijania.

To bardzo ważne przy kontenerach o stałej wysokości lub szerokości.

Składnia: overflow: wartość;

Wartość Co robi
visible treść wychodzi poza element
hidden ukrywa nadmiar treści
scroll zawsze pokazuje paski przewijania
auto dodaje scroll tylko gdy potrzeba

Domyślna wartość to visible, czyli nic nie jest obcinane.

Jeśli nie ustawimy overflow, treść może „wylewać się” z elementu.

initial przywraca visible, a inherit bierze ustawienie od rodzica.

overflow nie jest dziedziczone automatycznie.

Często używa się go razem z height lub max-height.

div {
    width: 200px;
    height: 100px;
    overflow: hidden;
}
.box {
    overflow: auto;
}

Przykłady użycia:

.panel {
    width: 250px;
    height: 120px;
    overflow: scroll;
}
.card {
    overflow: hidden;
}
.text-box {
    max-height: 100px;
    overflow: auto;
}
section {
    overflow: visible;
}

Najczęściej używa się auto, żeby scroll pojawiał się tylko gdy trzeba.
