Właściwości tła w CSS służą do ustawiania wyglądu tła elementu. Możemy dodać kolor, obrazek, ustawić powtarzanie i pozycję.

Najczęściej łączy się kilka właściwości, żeby tło wyglądało normalnie, a nie „rozciągnięte na siłę”.

To jedna z podstaw CSS przy robieniu layoutów.

Składnia: background: wartość; albo osobne właściwości tła.

Właściwość Co robi
background-color ustawia kolor tła
background-image ustawia obraz jako tło
background-repeat określa czy obrazek się powtarza
background-position ustawia pozycję obrazka
background-size skaluje obraz (np. cover, contain)
background-attachment czy tło scrolluje czy jest stałe
background skrót wszystkich naraz

Domyślnie tło jest przezroczyste, a obrazek nie istnieje (none).

background-repeat domyślnie = repeat, czyli obrazek się powtarza.

initial resetuje ustawienia, a inherit bierze z rodzica.

Ważne: żeby background-repeat było widoczne, obrazek NIE może być rozciągany przez background-size: cover.

Dlatego w przykładach używamy małych obrazków.

div {
    background-image: url("../img/tlo1.jpg");
    background-repeat: repeat;
}
div {
    background-image: url("../img/tlo1.jpg");
    background-repeat: no-repeat;
}

Przykłady użycia:

body {
    background-image: url("../img/tlo1.jpg");
    background-repeat: repeat;
}
.box {
    background-image: url("../img/tlo2.jpg");
    background-repeat: no-repeat;
}
header {
    background-image: url("../img/tlo3.jpg");
    background-repeat: repeat-x;
}
section {
    background-image: url("../img/tlo4.png");
    background-repeat: repeat-y;
}

Różne wartości dają różne efekty wizualne.
