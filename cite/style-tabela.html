Dlaczego tabele wymagają specjalnego stylowania?

Domyślna tabela HTML wygląda brzydko - brak obramowania, brak odstępów, komórki kleją się do siebie. Do sensownego wyglądu potrzebujesz kilku właściwości CSS, które działają specyficznie dla tabel i nie mają odpowiedników w innych elementach.

Najważniejsze z nich to border-collapse i border-spacing - kontrolują czy obramowania komórek się łączą czy są osobne. Reszta to standardowe CSS: tło, padding, kolory, czcionka.

border-collapse - najważniejsza właściwość

Domyślnie każda komórka tabeli ma własne obramowanie, co powoduje podwójne linie między komórkami. border-collapse: collapse scala te obramowania w jedno - i to pierwsza rzecz którą ustawiasz przy każdej tabeli.

table {

  border-collapse: collapse;

}



table {

  border-collapse: separate;

  border-spacing: 4px;

}

Wartości:

Wartość Co robi
collapse Obramowania sąsiednich komórek łączą się w jedną linię - wygląda schludnie
separate Każda komórka ma swoje własne obramowanie, między nimi jest odstęp kontrolowany przez border-spacing

Obramowania komórek

Border ustawiasz na th i td, nie na table - bo border na table daje tylko zewnętrzną ramkę całej tabeli, bez linii między komórkami.

th, td {

  border: 1px solid #ccc;

}



table {

  border-collapse: collapse;

}

Możesz też robić selektywne obramowania - np. tylko poziome linie (styl "liniowy"):

th, td {

  border-bottom: 1px solid #e0e0e0;

  border-top: none;

  border-left: none;

  border-right: none;

}

Padding, wyrównanie, szerokości

Bez paddingu tekst w komórkach przylega do krawędzi i jest nieczytelny. Dodaj go zawsze:

th, td {

  padding: 10px 16px;

}

Wyrównanie tekstu - domyślnie <th> jest wyśrodkowany i pogrubiony, <td> jest do lewej. Możesz to zmienić:

th {

  text-align: left;

}



td:last-child {

  text-align: right;

}

Szerokości kolumn - tabela domyślnie dopasowuje szerokość do treści. Możesz to kontrolować:

table {

  width: 100%;

  table-layout: fixed;

}



td:first-child {

  width: 40%;

}

table-layout: fixed sprawia że przeglądarka nie oblicza szerokości na podstawie treści tylko respektuje Twoje wartości - tabela renderuje się szybciej i kolumny mają przewidywalne szerokości.

Kolory, naprzemienne wiersze, hover

Najczęstsze techniki stylowania wierszy:

thead {

  background: #333;

  color: #fff;

}



tbody tr:nth-child(even) {

  background: #f5f5f5;

}



tbody tr:hover {

  background: #e8e0ff;

}

:nth-child(even) zaznacza co drugi wiersz - tzw. efekt zebry. :hover podświetla wiersz po najechaniu myszą - przydatne w tabelach z dużą ilością danych.

Stylowanie konkretnej sekcji - thead, tbody, tfoot jako selektory CSS: 

tfoot {

  border-top: 2px solid #333;

  font-weight: bold;

  background: #f0f0f0;

}
