Właściwość text-align służy do ustawiania wyrównania tekstu w poziomie. Dzięki niej możemy zdecydować, czy tekst będzie po lewej, prawej stronie, wyśrodkowany albo rozciągnięty.

Najczęściej używa się jej w akapitach, nagłówkach i blokach tekstowych. Nie działa na elementy liniowe pojedynczo, tylko na kontener tekstu.

Jest bardzo ważna przy tworzeniu czytelnych układów stron.

Składnia: text-align: wartość;

Wartość Co robi
left Wyrównuje tekst do lewej strony
right Wyrównuje tekst do prawej strony
center Wyśrodkowuje tekst
justify Rozciąga tekst na całą szerokość bloku
start Wyrównanie zależne od kierunku pisania (LTR/RTL)
end Wyrównanie do końca linii
inherit Dziedziczy wartość od elementu nadrzędnego
initial Przywraca wartość domyślną
unset Działa jak inherit lub initial zależnie od kontekstu 
p {

    text-align: center;

}

Domyślna wartość to left, czyli wyrównanie do lewej strony.

Jeśli nie ustawimy tej właściwości, tekst w językach takich jak polski będzie automatycznie wyrównany do lewej.

Wartość initial przywraca domyślne wyrównanie, a inherit przejmuje ustawienie od rodzica.

Właściwość text-align nie zawsze jest dziedziczona bezpośrednio, ale w praktyce zachowuje się jak dziedziczona dla bloków tekstowych.

Jeśli ustawimy wyrównanie dla div, jego elementy potomne często będą wyglądały tak samo.

div {

    text-align: center;

}

Możemy nadpisać to w dzieciach:

p {

    text-align: left;

}

Przykłady użycia:

Wyśrodkowany nagłówek:

h1 {

    text-align: center;

}

Tekst wyrównany do prawej:

.prawa {

    text-align: right;

}

Tekst wyjustowany:

p {

    text-align: justify;

}

Domyślne wyrównanie:

body {

    text-align: left;

}

Wybierz wyrównanie tekstu i zobacz jak zmienia się układ akapitu.
