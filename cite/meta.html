Znacznik <meta> służy do przekazywania informacji o stronie internetowej przeglądarce, wyszukiwarkom i innym programom. Umieszcza się go wewnątrz sekcji <head>.

Jest elementem pustym, więc nie zawiera treści i nie ma znacznika zamykającego.

Używamy go kiedy chcemy:

  • ustawić kodowanie znaków strony
  • określić opis strony dla wyszukiwarek
  • ustawić słowa kluczowe
  • sterować skalowaniem strony na urządzeniach mobilnych
  • przekazać informacje dla robotów wyszukiwarek
  • odświeżyć lub przekierować stronę
  • przekazać dodatkowe dane aplikacjom i przeglądarkom

Najczęściej spotykane są znaczniki ustawiające charset, viewport oraz robots.

Atrybut Wartości Co robi
charset UTF-8 i inne kodowania Określa kodowanie znaków dokumentu
name description, keywords, author, viewport, robots, application-name, generator, referrer, color-scheme, theme-color Definiuje rodzaj metadanych
content Dowolny tekst zależny od atrybutu name Zawiera wartość metadanych
http-equiv refresh, content-type, default-style, x-ua-compatible, content-security-policy Przekazuje instrukcje podobne do nagłówków HTTP
media Zapytania media, np. screen and (max-width: 600px) Określa dla jakich urządzeń obowiązują dane metadane

Znacznik <meta> ma znaczenie semantyczne, ponieważ opisuje stronę i przekazuje informacje o dokumencie. Czytniki ekranu zwykle nie odczytują większości metadanych użytkownikowi, ale przeglądarki, wyszukiwarki i inne narzędzia wykorzystują je do poprawnego działania.

Google może używać opisu z description, a przeglądarka korzysta z charset i viewport podczas wyświetlania strony.

Właściwość Wartość
Typ elementu Pusty
Znacznik zamykający Nie (niekontenerowy)
Semantyka Metadane dokumentu HTML
Może zawierać Żadnych elementów ani tekstu
Może być wewnątrz Głównie sekcji <head>
Domyślny display none
