Czym są Google Fonts?

Google Fonts to darmowa biblioteka czcionek dostępna online. Pozwala używać niestandardowych krojów pisma bez instalowania ich na komputerze użytkownika.

Wystarczy dodać odpowiedni znacznik link do sekcji head, a następnie użyć nazwy czcionki we właściwości font-family.

Jak dodać czcionkę?

Przykład dla czcionki Roboto:

<link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet">

Następnie:

body {

    font-family: "Roboto", sans-serif;

}

Dlaczego poprzedni symulator nie działał?

Samo wpisanie nazwy czcionki w JavaScript nie powoduje pobrania jej z internetu. Czcionka musi być wcześniej załadowana przez znaczniki link w sekcji head.

Jeżeli przeglądarka nie zna danej czcionki, wyświetli czcionkę zastępczą i zmiana będzie niewidoczna.

Przykład użycia

h1 {

    font-family: "Montserrat", sans-serif;

}



p {

    font-family: "Open Sans", sans-serif;

}
