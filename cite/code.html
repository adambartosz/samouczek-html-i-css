Znacznik <code> służy do oznaczania fragmentów kodu komputerowego w tekście. Zmienia sposób wyświetlania tekstu na monospace.

Jest elementem liniowym.

Używamy go kiedy chcemy:

  • pokazać kod HTML, CSS lub JS
  • wyróżnić nazwę funkcji
  • opisać komendy techniczne

Znacznik ma znaczenie semantyczne – informuje, że tekst to kod. Czytniki ekranów mogą zmieniać sposób odczytu takiego fragmentu.

Właściwość Wartość
Typ elementu Liniowy
Znacznik zamykający Tak (kontenerowy)
Semantyka Fragment kodu komputerowego
Może zawierać Tekst
Może być wewnątrz Blokowych i liniowych
Domyślny display inline
