Co to są jednostki CSS?

Jednostki CSS określają, w jakich wartościach zapisujemy rozmiary w stylach. Dzięki nim ustawiamy szerokości, wysokości, marginesy, fonty i inne parametry wyglądu strony.

Bez jednostek przeglądarka nie wie, czy coś ma być duże, małe, czy średnie. Dlatego zawsze trzeba je podawać.

Najważniejsze jest to, że jednostki dzielą się na względne i bezwzględne.

Podział jednostek CSS

W CSS mamy dwa główne typy jednostek:

  • jednostki bezwzględne – stałe, nie zależą od niczego
  • jednostki względne – zależą od innych wartości (np. ekranu lub rodzica)

W praktyce częściej używa się jednostek względnych, bo lepiej działają na różnych urządzeniach.

Jednostki bezwzględne

Jednostki bezwzględne mają stałą wielkość. Nie zmieniają się w zależności od ekranu czy ustawień użytkownika.

Jednostka Opis
px piksele – najczęściej używana jednostka w CSS
cm centymetry – rzadko używane w webie
mm milimetry
in cale (1in = 2.54cm)
pt punkty typograficzne (1pt = 1/72 cala)
pc pica (1pc = 12pt)

Najczęściej używaną jednostką bezwzględną jest px.

Jednostki względne

Jednostki względne zmieniają swoją wartość w zależności od kontekstu, np. rozmiaru ekranu, rodzica albo czcionki.

Jednostka Opis
% Procent względem elementu nadrzędnego
em Względem rozmiaru czcionki elementu rodzica
rem Względem rozmiaru czcionki elementu root (html)
vw 1% szerokości okna przeglądarki
vh 1% wysokości okna przeglądarki
vmin Mniejsza wartość z vw i vh
vmax Większa wartość z vw i vh
ch Szerokość znaku „0” w danej czcionce
ex Wysokość małej litery x

Najczęściej używane są: %, rem, vw i vh.

Różnica między px a rem

px jest stałe i nie zmienia się przy zmianie ustawień użytkownika.

rem zależy od ustawień czcionki w elemencie html, więc lepiej skaluje się na różnych urządzeniach.

html {
    font-size: 16px;
}

p {
    font-size: 1rem;
}

h1 {
    font-size: 2rem;
}

Przykłady użycia jednostek

/* stała szerokość */
.box {
    width: 300px;
}

/* szerokość zależna od rodzica */
.container {
    width: 80%;
}

/* wysokość ekranu */
.hero {
    height: 100vh;
}

/* rozmiar czcionki */
.text {
    font-size: 1.2rem;
}

/* margines zależny od czcionki */
.card {
    padding: 2em;
}

Dlaczego używa się jednostek względnych?

  • lepiej działają na telefonach
  • łatwiej robić responsywne strony
  • skalują się z tekstem
  • ułatwiają dostępność strony

Dlatego nowoczesne strony prawie zawsze używają rem i %.
