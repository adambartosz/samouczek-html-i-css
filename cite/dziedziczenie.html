Co to jest dziedziczenie?

Dziedziczenie (inheritance) to mechanizm CSS, dzięki któremu niektóre właściwości ustawione dla elementu nadrzędnego są automatycznie przejmowane przez jego elementy potomne.

Dzięki temu nie trzeba wielokrotnie powtarzać tych samych reguł dla każdego elementu osobno. Wystarczy ustawić właściwość dla rodzica, a dzieci często otrzymają ją automatycznie.

Dziedziczenie jest jednym z najważniejszych mechanizmów działania CSS i pozwala pisać krótszy oraz bardziej czytelny kod.

Jak działa dziedziczenie?

Załóżmy, że mamy taki kod HTML:

<div>

    <p>Pierwszy akapit</p>

    <p>Drugi akapit</p>

</div>

Oraz taki CSS:

div {

    color: blue;

}

Oba akapity odziedziczą kolor tekstu od elementu div i zostaną wyświetlone na niebiesko.

Element nadrzędny nazywany jest rodzicem, a znajdujące się w nim elementy potomne nazywane są dziećmi.

Właściwości dziedziczone

Nie wszystkie właściwości CSS są dziedziczone automatycznie. Najczęściej dziedziczone są właściwości związane z tekstem.

Właściwość Dziedziczona
color Tak
font-family Tak
font-size Tak
font-style Tak
font-weight Tak
line-height Tak
text-align Tak
visibility Tak

Najczęściej właśnie te właściwości ustawiamy dla elementu body, aby obowiązywały na całej stronie.

Właściwości niedziedziczone

Wiele właściwości odpowiedzialnych za układ strony nie jest dziedziczonych automatycznie.

Właściwość Dziedziczona
margin Nie
padding Nie
border Nie
width Nie
height Nie
background-color Nie
display Nie
position Nie

Jeżeli ustawimy margines dla rodzica, dzieci nie otrzymają go automatycznie.

Słowa kluczowe związane z dziedziczeniem

CSS udostępnia kilka specjalnych wartości pozwalających sterować dziedziczeniem.

Wartość Działanie
inherit Wymusza przejęcie wartości od rodzica
initial Przywraca domyślną wartość właściwości
unset Działa jak inherit lub initial w zależności od właściwości
revert Przywraca wartość wynikającą ze stylów przeglądarki lub wcześniejszych reguł

Przykład użycia:

p {

    color: inherit;

}

Kolor tekstu zostanie pobrany od elementu nadrzędnego.

Przykłady praktyczne

Dziedziczenie czcionki dla całej strony:

body {

    font-family: Arial, sans-serif;

}

Wszystkie elementy tekstowe odziedziczą ten krój pisma.

Dziedziczenie koloru:

.menu {

    color: navy;

}

Linki, akapity i inne elementy tekstowe znajdujące się w menu zwykle przejmą ten kolor.

Wymuszenie dziedziczenia:

button {

    font-family: inherit;

}

Przycisk użyje tej samej czcionki co jego rodzic.

Drzewo dziedziczenia

Dziedziczenie przebiega od elementów nadrzędnych do potomnych.

body

 └── div.container

    .....├── h1

      .....├── p

      .....└── ul

           ..........├── li

           ..........└── li

Jeżeli ustawimy kolor dla body, wszystkie elementy znajdujące się niżej w drzewie mogą go odziedziczyć.

Im wyżej ustawiona właściwość dziedziczona, tym mniej kodu trzeba napisać.
