Co to jest menu rozwijane?

Menu rozwijane (dropdown) to menu, w którym po najechaniu lub kliknięciu na pozycję pojawia się lista dodatkowych linków – podmenu. Używa się go gdy strona ma dużo podstron i nie chcemy upychać wszystkiego w głównym pasku nawigacji.

Zbudowane jest z zagnieżdżonej listy <ul> wewnątrz <li>. Domyślnie podmenu jest ukryte przez CSS i pokazuje się dopiero przy :hover lub przez JavaScript.

Struktura HTML

Podmenu to po prostu lista wewnątrz elementu listy:

<nav>

  <ul>

    <li><a href="index.html">Strona główna</a></li>

    <li>

      <a href="oferta.html">Oferta</a>

      <ul>

        <li><a href="web.html">Strony www</a></li>

        <li><a href="sklepy.html">Sklepy internetowe</a></li>

        <li><a href="aplikacje.html">Aplikacje</a></li>

      </ul>

    </li>

    <li><a href="kontakt.html">Kontakt</a></li>

  </ul>

</nav>

Ważne: <li> z podmenu musi mieć position: relative, żeby podmenu mogło się pozycjonować względem niego.

CSS – dropdown na hover

Najpopularniejsza metoda – podmenu pokazuje się przy najechaniu myszką:

nav ul {

  list-style: none;

  margin: 0;

  padding: 0;

  display: flex;

}



nav ul li {

  position: relative;

}



nav ul li a {

  display: block;

  padding: 10px 18px;

  text-decoration: none;

  color: white;

  background: #333;

}



nav ul li a:hover {

  background: #555;

}



nav ul ul {

  display: none;

  position: absolute;

  top: 100%;

  left: 0;

  min-width: 180px;

  z-index: 100;

}



nav ul li:hover > ul {

  display: block;

}



nav ul ul li a {

  background: #444;

}



nav ul ul li a:hover {

  background: #666;

}

Kluczowe właściwości:

  • position: relative na li – punkt odniesienia dla podmenu
  • position: absolute na ul ul – podmenu wyrywa się z normalnego przepływu i nakłada na treść
  • top: 100% – podmenu zaczyna się dokładnie pod rodzicem
  • display: none – podmenu domyślnie ukryte
  • li:hover > ul – > oznacza bezpośrednie dziecko, żeby nie pokazywać głębszych poziomów naraz
  • z-index: 100 – podmenu przykrywa inne elementy strony

CSS – płynne pokazywanie (opacity + transition)

Zamiast skakać z ukrytego do widocznego, można dodać płynne pojawienie się:

nav ul ul {

  display: block;

  position: absolute;

  top: 100%;

  left: 0;

  min-width: 180px;

  z-index: 100;

  opacity: 0;

  pointer-events: none;

  transform: translateY(-6px);

  transition: opacity 0.2s, transform 0.2s;

}



nav ul li:hover > ul {

  opacity: 1;

  pointer-events: auto;

  transform: translateY(0);

}

Tu nie używamy display: none, bo z nim transition nie działa. Zamiast tego ukrywamy przez opacity: 0 i blokujemy klikanie przez pointer-events: none.

Dropdown przez JavaScript

Hover nie działa na urządzeniach dotykowych. Dlatego często robi się dropdown otwierany kliknięciem:

<li class="ma-podmenu">

  <a href="oferta.html">Oferta ▾</a>

  <ul class="podmenu">

    <li><a href="web.html">Strony www</a></li>

  </ul>

</li>
.podmenu {

  display: none;

  position: absolute;

  top: 100%;

  left: 0;

  z-index: 100;

}



.podmenu.otwarte {

  display: block;

}
var przyciski = document.querySelectorAll(".ma-podmenu > a");



przyciski.forEach(function(a) {

  a.addEventListener("click", function(e) {

    e.preventDefault();

    var podmenu = a.nextElementSibling;

    podmenu.classList.toggle("otwarte");

  });

});



document.addEventListener("click", function(e) {

  if (!e.target.closest(".ma-podmenu")) {

    document.querySelectorAll(".podmenu").forEach(function(p) {

      p.classList.remove("otwarte");

    });

  }

});

classList.toggle dodaje klasę jeśli jej nie ma, usuwa jeśli jest. e.target.closest sprawdza czy kliknięto wewnątrz elementu z daną klasą – dzięki temu kliknięcie poza menu je zamknie.
