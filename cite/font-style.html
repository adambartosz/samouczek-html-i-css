Właściwość font-style określa styl wyświetlania tekstu. Najczęściej używa się jej do włączania kursywy lub powrotu do zwykłego wyglądu liter.

Nie zmienia ona rozmiaru ani grubości czcionki. Wpływa wyłącznie na sposób rysowania znaków przez przeglądarkę.

Jest często stosowana w cytatach, wyróżnieniach oraz elementach o charakterze pomocniczym.

Składnia: font-style: wartość;

Wartość Co robi
normal Standardowy wygląd tekstu bez kursywy
italic Używa prawdziwej kursywy dostępnej w danej czcionce
oblique Pochyla tekst. Jeśli czcionka nie ma kursywy, przeglądarka tworzy ją sztucznie
oblique 10deg Pochyla tekst pod określonym kątem
oblique 20deg Pochyla tekst pod wskazanym kątem od 0 do 90 stopni
inherit Przejmuje wartość od elementu nadrzędnego
initial Przywraca wartość początkową właściwości
unset Działa jak inherit albo initial zależnie od sytuacji
revert Przywraca styl wynikający z domyślnych arkuszy stylów
revert-layer Przywraca wartość z wcześniejszej warstwy CSS 
p {

    font-style: italic;

}

Domyślną wartością właściwości font-style jest normal. Oznacza to, że tekst jest wyświetlany bez pochylenia.

Jeżeli nie ustawimy tej właściwości samodzielnie, przeglądarka użyje zwykłego stylu czcionki.

Wartość initial przywraca ustawienie normal, natomiast inherit powoduje przejęcie wartości od elementu nadrzędnego.

font-style: initial;
font-style: inherit;

Właściwość font-style jest dziedziczona. Jeżeli ustawimy kursywę dla elementu nadrzędnego, potomkowie również będą wyświetlani kursywą.

Dzięki temu można jednym zapisem zmienić wygląd większej części strony.

article {

    font-style: italic;

}

Wartość inherit wymusza pobranie ustawienia od rodzica. Wartość initial usuwa dziedziczenie i przywraca zwykły styl tekstu.

span {

    font-style: inherit;

}
span {

    font-style: initial;

}

Kursywa dla cytatów:

blockquote {

    font-style: italic;

}

Powrót do zwykłego stylu tekstu:

p {

    font-style: normal;

}

Pochylenie tekstu bez używania kursywy:

.uwaga {

    font-style: oblique;

}

Pochylenie pod konkretnym kątem:

.efekt {

    font-style: oblique 15deg;

}
