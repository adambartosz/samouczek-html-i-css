Co to jest responsywność?

Responsywność (RWD – Responsive Web Design) to podejście do tworzenia stron, w którym strona dopasowuje swój wygląd do rozmiaru ekranu urządzenia. Ta sama strona ma wyglądać dobrze na monitorze, tablecie i telefonie.

Osiąga się to głównie przez CSS – używamy elastycznych jednostek, Flexboxa, Grida i media queries, które pozwalają zmieniać style w zależności od szerokości okna przeglądarki.

Viewport i znacznik meta

Pierwsza rzecz, bez której nic nie działa – znacznik <meta name="viewport"> w <head>: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Bez niego mobilna przeglądarka udaje, że ekran ma ~980px szerokości i skaluje całą stronę w dół. Z tym znacznikiem szerokość strony równa się faktycznej szerokości ekranu urządzenia.

  • width=device-width – szerokość viewportu równa szerokości ekranu
  • initial-scale=1.0 – brak domyślnego powiększenia przy ładowaniu

Media queries

Media queries to warunki w CSS – jeśli ekran spełnia warunek, stosuj te style:

@media (max-width: 768px) {

  .kolumny {

    flex-direction: column;

  }

}

Najczęstsze warunki:

  • max-width – style aktywne gdy ekran jest węższy niż podana wartość
  • min-width – style aktywne gdy ekran jest szerszy niż podana wartość
  • Można łączyć: @media (min-width: 600px) and (max-width: 900px)

Typowe punkty graniczne (breakpointy):

/* telefony */
@media (max-width: 576px) { ... }



/* tablety */
@media (max-width: 768px) { ... }



/* małe laptopy */
@media (max-width: 992px) { ... }



/* duże ekrany */
@media (max-width: 1200px) { ... }

To nie są sztywne zasady – breakpointy ustawiasz tam, gdzie Twój layout zaczyna wyglądać źle.

Mobile first vs desktop first

Są dwa podejścia do pisania responsywnego CSS:

Desktop first – piszesz style dla dużego ekranu, a potem nadpisujesz dla mniejszych przez max-width: 

.kolumny {

  display: flex;

  gap: 20px;

}



@media (max-width: 768px) {

  .kolumny {

    flex-direction: column;

  }

}

Mobile first – piszesz style dla telefonu, a potem dodajesz dla większych ekranów przez min-width. To podejście jest zalecane, bo telefony to dziś większość ruchu: 

.kolumny {

  display: flex;

  flex-direction: column;

  gap: 20px;

}



@media (min-width: 768px) {

  .kolumny {

    flex-direction: row;

  }

}

Elastyczne jednostki

Zamiast stałych pikseli warto używać jednostek, które same się skalują:

  • % – procent szerokości rodzica. width: 50% to połowa rodzica
  • vw – procent szerokości okna przeglądarki. 100vw = pełna szerokość okna
  • vh – procent wysokości okna. 100vh = pełna wysokość okna
  • em – wielokrotność rozmiaru czcionki rodzica. Jeśli rodzic ma font-size: 16px, to 1em = 16px
  • rem – wielokrotność rozmiaru czcionki elementu <html>. Bardziej przewidywalne niż em

Do szerokości kontenerów przydaje się też max-width:

.kontener {

  width: 100%;

  max-width: 1200px;

  margin: 0 auto;

}

Kontener zajmuje całą szerokość, ale nie rozciągnie się powyżej 1200px. margin: 0 auto wyśrodkowuje go na szerokich ekranach.

Responsywne obrazki

Obrazek bez responsywności wyłazi poza kontener na wąskim ekranie. Podstawowa reguła:

img {

  max-width: 100%;

  height: auto;

}

max-width: 100% sprawia że obrazek nigdy nie będzie szerszy niż jego kontener. height: auto zachowuje proporcje.

Jeśli chcesz serwować różne rozmiary obrazka dla różnych ekranów, użyj atrybutu srcset:

<img

  src="zdjecie-duze.jpg"

  srcset="zdjecie-male.jpg 480w, zdjecie-srednie.jpg 768w, zdjecie-duze.jpg 1200w"

  sizes="(max-width: 480px) 480px, (max-width: 768px) 768px, 1200px"

  alt="opis zdjecia"

>
