Co to jest model pudełkowy?

Model pudełkowy (box model) w CSS opisuje każdy element jako prostokąt. Każdy taki element ma warstwy: content, padding, border i margin.

To jest podstawowa rzecz w CSS, bo wszystko na stronie da się traktować jak pudełko.

Dzięki temu łatwo kontrolować odstępy i rozmiary elementów.

Budowa modelu pudełkowego

Każdy element składa się z 4 warstw:

  • content – treść elementu
  • padding – odstęp wewnętrzny
  • border – obramowanie
  • margin – odstęp zewnętrzny

Te warstwy razem tworzą jeden model pudełkowy.

Podstawowe właściwości

Właściwość Opis
width szerokość contentu
height wysokość contentu
padding odstęp wewnętrzny
border obramowanie
margin odstęp zewnętrzny
box-sizing określa sposób liczenia rozmiaru

Box-sizing

Domyślnie jest content-box, czyli padding i border zwiększają rozmiar elementu.

border-box wlicza wszystko do szerokości i wysokości.

div {
    box-sizing: border-box;
}

Przykład CSS

.box {
    width: 200px;
    height: 100px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}

Dlaczego to ważne?

  • każdy element to pudełko
  • łatwiej robić layout
  • Flexbox i Grid bazują na tym modelu
  • kontrola odstępów
