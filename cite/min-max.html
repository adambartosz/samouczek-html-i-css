Właściwości min-width i max-width kontrolują minimalną i maksymalną szerokość elementu. Dzięki nim element nie może być ani za mały, ani za duży.

min-width ustala najmniejszą możliwą szerokość, a max-width największą.

Stosuje się je głównie w responsywnych stronach.

Składnia: właściwość: wartość;

Wartość Co robi
px stała szerokość w pikselach
% procent względem rodzica
vw procent szerokości okna
none brak ograniczenia (dla max-width)
inherit dziedziczenie od rodzica
initial wartość domyślna

Domyślnie min-width wynosi 0, a max-width to none.

To oznacza, że element może się kurczyć i rozciągać bez ograniczeń.

initial resetuje wartości, a inherit przejmuje je od rodzica.

Te właściwości są bardzo ważne w responsywności.

Przykład: obrazek nigdy nie wyjdzie poza ekran.

img {
    max-width: 100%;
}

Można też wymusić minimalny rozmiar elementu.

div {
    min-width: 200px;
}

Przykłady użycia:

.box {
    min-width: 200px;
    max-width: 600px;
}
img {
    max-width: 100%;
    height: auto;
}
.container {
    min-width: 300px;
    max-width: 1200px;
}

Dzięki temu layout nie „rozjeżdża się” na różnych ekranach.
