Co oznaczają elementy blokowe i liniowe?

W HTML każdy element ma domyślny sposób wyświetlania. Najczęściej spotykamy dwa typy elementów: blokowe oraz liniowe.

Różnica między nimi wpływa na układ strony, rozmieszczenie elementów i sposób działania CSS.

Zrozumienie tej różnicy jest bardzo ważne podczas nauki HTML i CSS.

Elementy blokowe

Element blokowy rozpoczyna się od nowej linii i domyślnie zajmuje całą dostępną szerokość swojego rodzica.

Jeżeli obok siebie umieścimy kilka elementów blokowych, każdy pojawi się w osobnym wierszu.

<h1>Nagłówek</h1>

<p>Pierwszy akapit</p>

<p>Drugi akapit</p>

Efekt:

Nagłówek

Pierwszy akapit

Drugi akapit

Każdy element zostanie umieszczony pod poprzednim.

Elementy liniowe

Element liniowy nie rozpoczyna nowej linii. Zajmuje tylko tyle miejsca, ile potrzebuje jego zawartość.

Może znajdować się obok innych elementów w tym samym wierszu.

<p>

To jest <strong>ważny</strong> tekst.

</p>

Element <strong> nie przenosi tekstu do nowej linii.

Wyświetla się dokładnie tam, gdzie został umieszczony.

Znaczniki span są elementami liniowymi.

Display i zmiana zachowania elementów

Za pomocą CSS można zmienić sposób wyświetlania elementu.

Element liniowy można zmienić w blokowy:

span {

    display: block;

}

Element blokowy można zmienić w liniowy:

div {

    display: inline;

}

Istnieje także wartość inline-block, która łączy cechy obu typów.

Inline-block

Element typu inline-block zachowuje się jak element liniowy, ale można ustawiać jego szerokość i wysokość.

.box {

    display: inline-block;

    width: 150px;

    height: 50px;

}

Jest to bardzo często wykorzystywane przy tworzeniu menu, przycisków i prostych układów.

Najczęstsze błędy początkujących

  • używanie wielu elementów br zamiast CSS
  • mylenie div i span
  • nieznajomość domyślnego display elementów
  • próba ustawiania width na zwykłych elementach inline
  • ignorowanie semantycznych znaczników HTML

Większość problemów z układem strony wynika właśnie z nieznajomości różnic między elementami blokowymi i liniowymi.
