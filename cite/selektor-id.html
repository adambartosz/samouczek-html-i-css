Co to są selektory id i class?

Selektory id oraz class służą do wybierania elementów HTML i przypisywania im stylów CSS.

Selektor id odnosi się do jednego konkretnego elementu, natomiast selektor class może być używany przez wiele elementów jednocześnie.

Oba selektory są bardzo często wykorzystywane podczas tworzenia stron internetowych.

Selektor id

Selektor id wykorzystuje atrybut id. W CSS zapisuje się go za pomocą znaku #.

<h1 id="logo">Moja strona</h1>
#logo {

    color: red;

}

Identyfikator powinien być unikalny, czyli na jednej stronie nie powinno być dwóch elementów z tym samym id.

Selektor class

Selektor class wykorzystuje atrybut class. W CSS zapisuje się go za pomocą znaku .. 

<p class="ważny">Tekst</p>

<p class="ważny">Kolejny tekst</p>
.ważny {

    color: blue;

}

Tę samą klasę można przypisać wielu elementom jednocześnie.

Porównanie id i class

Cecha id class
Znak w CSS # .
Unikalność Tak Nie
Może wystąpić wiele razy Nie Tak
Typowe zastosowanie Pojedynczy element Grupa elementów
Specyficzność Wyższa Niższa

Przykłady użycia

Id dla logo strony:

<h1 id="logo">Firma</h1>

Klasa dla wielu przycisków:

<button class="przycisk">Zapisz</button>

<button class="przycisk">Usuń</button>

CSS:

#logo {

    font-size: 40px;

}



.przycisk {

    padding: 10px;

}

Kiedy używać id, a kiedy class?

  • id używaj dla pojedynczych elementów, np. logo, menu, stopka
  • class używaj dla grup elementów mających wspólny wygląd
  • większość stylowania wykonuje się za pomocą klas
  • id często wykorzystuje się także w JavaScript i kotwicach

W nowoczesnych projektach klasy są używane znacznie częściej niż identyfikatory.
