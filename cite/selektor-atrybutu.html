Co to jest selektor atrybutu?

Selektor atrybutu pozwala wybierać elementy HTML na podstawie ich atrybutów lub wartości tych atrybutów.

Dzięki niemu można stylować elementy bez używania klas i identyfikatorów. Przeglądarka sprawdza, czy element posiada określony atrybut lub konkretną wartość.

Selektory atrybutów są często używane przy formularzach, linkach i elementach posiadających specjalne właściwości.

Podstawowa składnia

Najprostsza forma sprawdza, czy element posiada dany atrybut.

[disabled] {

    opacity: 0.5;

}

Powyższa reguła wybierze wszystkie elementy posiadające atrybut disabled.

Można też sprawdzać konkretną wartość:

input[type="email"] {

    border: 2px solid green;

}

W tym przypadku zostaną wybrane tylko pola formularza z atrybutem type="email".

Rodzaje selektorów atrybutów

Selektor Przykład Działanie
[atrybut] [disabled] Element posiada wskazany atrybut
[atrybut="wartość"] [type="text"] Dokładnie określona wartość
[atrybut~="wartość"] [class~="box"] Zawiera słowo oddzielone spacjami
[atrybut|="wartość"] [lang|="pl"] Dokładna wartość lub wartość z myślnikiem
[atrybut^="wartość"] [href^="https"] Zaczyna się od podanego tekstu
[atrybut$="wartość"] [href$=".pdf"] Kończy się podanym tekstem
[atrybut*="wartość"] [href*="google"] Zawiera podany fragment

Praktyczne przykłady

Wyróżnienie wszystkich pól e-mail:

input[type="email"] {

    border: 2px solid green;

}

Stylowanie linków HTTPS:

a[href^="https"] {

    font-weight: bold;

}

Stylowanie plików PDF:

a[href$=".pdf"] {

    color: red;

}

Stylowanie wyłączonych pól:

input[disabled] {

    opacity: 0.5;

}

Kiedy używać selektorów atrybutów?

  • gdy elementy mają wspólny atrybut
  • podczas stylowania formularzy
  • przy rozróżnianiu typów pól input
  • do wykrywania określonych rodzajów linków
  • gdy nie chcemy dodawać dodatkowych klas
  • do stylowania elementów disabled, required lub checked

Selektory atrybutów są bardzo przydatne, ale zwykle są mniej czytelne od dobrze nazwanych klas CSS.
