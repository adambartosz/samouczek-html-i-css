Czym jest margin i padding?

margin i padding to dwie podstawowe właściwości CSS odpowiedzialne za odstępy w modelu pudełkowym.

Margin odpowiada za odstęp na zewnątrz elementu, a padding za odstęp wewnątrz elementu.

To jedna z najważniejszych rzeczy przy robieniu layoutu strony.

Różnica między margin a padding

  • margin – odstęp między elementami
  • padding – odstęp między treścią a krawędzią elementu

Margin „odpycha” element od innych, a padding „rozpycha” zawartość w środku.

Jak działa margin?

Margin tworzy pustą przestrzeń wokół elementu. Nie ma tła i nie wpływa na zawartość.

div {
    margin: 20px;
}

Można też ustawić każdą stronę osobno:

div {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 40px;
}

Jak działa padding?

Padding tworzy odstęp wewnątrz elementu. Zwiększa przestrzeń między treścią a obramowaniem.

div {
    padding: 20px;
}

Podobnie jak margin, można ustawić każdą stronę osobno:

div {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

Najczęstsze użycie

Właściwość Kiedy używać
margin gdy chcesz zrobić odstęp między elementami
padding gdy chcesz zwiększyć przestrzeń w środku elementu

Przykład CSS

.box {
    margin: 20px;
    padding: 15px;
    border: 2px solid black;
}

Dlaczego to ważne?

  • kontroluje układ strony
  • poprawia czytelność
  • oddziela elementy wizualnie
  • jest podstawą layoutów

Bez margin i padding strona wyglądałaby „sklejona”.

Najczęstszy błąd

Używanie tylko margin albo tylko padding bez zrozumienia różnicy.

Często też ludzie próbują robić odstępy spacjami w HTML, co jest złe.

/* poprawnie */
div {
    margin: 20px;
    padding: 10px;
}
