Co to jest menu pionowe?

Menu pionowe to pasek nawigacyjny, w którym linki są ułożone jeden pod drugim w kolumnie. Najczęściej pojawia się jako boczny panel – po lewej lub po prawej stronie treści.

Buduje się je tak samo jak poziome: <nav> + <ul> + <li> + <a>. Różnica jest tylko w CSS – lista domyślnie jest już pionowa, więc nie trzeba jej "kłaść" jak w menu poziomym.

Struktura HTML

Struktura jest identyczna jak w menu poziomym:

<nav>

  <ul>

    <li><a href="index.html">Strona główna</a></li>

    <li><a href="o-nas.html">O nas</a></li>

    <li><a href="oferta.html">Oferta</a></li>

    <li><a href="kontakt.html">Kontakt</a></li>

  </ul>

</nav>

Używamy <nav>, bo czytniki ekranu i Google wiedzą wtedy, że to nawigacja. Lista <ul> ma sens, bo pozycje menu są równorzędne.

CSS – podstawowe menu pionowe

Lista jest już pionowa z natury, więc potrzebujemy tylko usunąć domyślne style i nadać wygląd linkom:

nav {

  width: 200px;

}



nav ul {

  list-style: none;

  margin: 0;

  padding: 0;

}



nav ul li a {

  display: block;

  padding: 10px 18px;

  text-decoration: none;

  color: white;

  background: #333;

}



nav ul li a:hover {

  background: #555;

}

Kluczowe rzeczy:

  • list-style: none – usuwa kropki z listy
  • margin: 0; padding: 0 – usuwa domyślne wcięcia
  • display: block na linku – cały wiersz jest klikalny, nie tylko tekst
  • width na nav – bez tego menu rozciągnie się na całą szerokość strony

Układanie obok treści

Menu pionowe ma sens tylko wtedy, gdy siedzi obok treści. Najwygodniej osiągnąć to Flexboxem na rodzicu:

.strona {

  display: flex;

  gap: 20px;

}



nav {

  width: 200px;

  flex-shrink: 0;

}



main {

  flex: 1;

}

Albo Gridem:

.strona {

  display: grid;

  grid-template-columns: 200px 1fr;

  gap: 20px;

}

flex-shrink: 0 na nav zapobiega temu, żeby Flexbox zwęził menu przy małym ekranie. flex: 1 na main sprawia, że treść zajmuje całą pozostałą przestrzeń.

Aktywna pozycja i separatory

Aktywną pozycję zaznaczamy klasą active:

<li><a href="index.html" class="active">Strona główna</a></li>
nav ul li a.active {

  background: #0066cc;

  color: white;

}

Separator między pozycjami można zrobić przez border-bottom na każdym li:

nav ul li {

  border-bottom: 1px solid #555;

}



nav ul li:last-child {

  border-bottom: none;

}

:last-child usuwa separator pod ostatnim elementem – bez tego byłby podwójny border przy krawędzi menu.

Menu z ikonami i podsekcjami

W menu pionowym łatwo dodać ikonę przed tekstem linku – wystarczy wstawić znak Unicode lub SVG:

<li><a href="index.html"><span class="ikona">☰</span> Strona główna</a></li>
.ikona {

  display: inline-block;

  width: 20px;

  margin-right: 8px;

  text-align: center;

}

Podsekcje (podmenu) tworzy się przez zagnieżdżoną listę <ul> wewnątrz <li>: 

<li>

  <a href="oferta.html">Oferta</a>

  <ul>

    <li><a href="web.html">Strony www</a></li>

    <li><a href="sklepy.html">Sklepy</a></li>

  </ul>

</li>
nav ul ul {

  padding-left: 16px;

}



nav ul ul li a {

  font-size: 0.9em;

  background: #444;

}
