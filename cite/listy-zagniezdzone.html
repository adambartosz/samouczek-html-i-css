Co to jest zagnieżdżanie list?

Zagnieżdżanie list w HTML to sytuacja, w której jedna lista znajduje się wewnątrz drugiej. Dzięki temu można budować wielopoziomowe struktury, np. menu albo spisy treści.

Każdy poziom jest tworzony przez <li>, a w nim może być kolejna lista <ul> albo <ol>.

Podstawowa zasada

Lista zawsze składa się z elementów <li>. Podlista musi być wewnątrz <li>, a nie obok niego. 

<ul>

  <li>Poziom 1

    <ul>

      <li>Poziom 2</li>

    </ul>

  </li>

</ul>

Przykład zagnieżdżenia

  • Frontend
    • HTML
    • CSS
    • JavaScript
  • Backend
    • PHP
    • Node.js

Najczęstsze błędy

  • Podlista poza <li>
  • Brak poprawnego domknięcia list
  • Mieszanie poziomów bez struktury
