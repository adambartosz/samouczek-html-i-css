Znaczniki <html>, <head> i <body> tworzą podstawowy szkielet każdej strony internetowej. Bez nich dokument HTML byłby niekompletny i trudniejszy do poprawnego interpretowania przez przeglądarkę.

<html> jest korzeniem całego dokumentu, <head> przechowuje informacje o stronie, a <body> zawiera treść widoczną dla użytkownika.

Są to elementy blokowe i kontenerowe, które organizują całą strukturę dokumentu.

Te znaczniki wykorzystujemy gdy chcemy:

  • utworzyć poprawny dokument HTML
  • określić język strony
  • ustawić kodowanie znaków
  • nadać tytuł karcie przeglądarki
  • podłączyć arkusze CSS
  • podłączyć pliki JavaScript
  • umieścić treść strony internetowej
  • zbudować strukturę zgodną ze standardami HTML
  • umożliwić poprawne działanie wyszukiwarek i czytników ekranu
  • przygotować stronę do walidacji

Nie istnieje praktyczna alternatywa dla tych elementów, ponieważ są one podstawą każdego dokumentu HTML.

Atrybut Wartości Co robi
lang (html) pl, en, de, fr, es, it i inne kody języków Określa główny język dokumentu
xmlns (html) adres przestrzeni nazw XML Używany głównie w dokumentach XHTML
profile (head - przestarzały) adres URL Dawniej określał metadane dokumentu

Znaczniki te mają bardzo duże znaczenie semantyczne.

<html> informuje przeglądarkę, gdzie rozpoczyna się dokument HTML. Atrybut lang pomaga czytnikom ekranu poprawnie odczytywać treść oraz wspiera tłumaczenia automatyczne.

<head> przechowuje metadane dokumentu, czyli informacje o stronie. Nie są one wyświetlane bezpośrednio użytkownikowi, ale są wykorzystywane przez przeglądarki, wyszukiwarki oraz różne narzędzia.

<body> oznacza główną część dokumentu zawierającą treść widoczną na stronie. Czytniki ekranu rozpoczynają analizę strony właśnie od zawartości tego elementu.

Właściwość Wartość
Typ elementu Blokowy
Znacznik zamykający Tak (kontenerowy)
Semantyka Podstawowa struktura dokumentu HTML
Może zawierać html: head i body, head: meta, title, link, script, body: większość elementów HTML
Może być wewnątrz html po DOCTYPE, head i body wewnątrz html
Domyślny display block
