Właściwość position określa, w jaki sposób element jest umieszczony w układzie strony. Decyduje o tym, czy element uczestniczy w normalnym przepływie dokumentu, czy jest z niego wyrwany i pozycjonowany ręcznie za pomocą top, right, bottom, left. Bez niej elementy układają się jeden pod drugim zgodnie z kolejnością w HTML.

Składnia: position: wartość;

Samo position decyduje o trybie. Żeby faktycznie przesunąć element, potrzebujesz jeszcze top, left, right lub bottom – działają tylko gdy position jest inne niż static. z-index kontroluje kolejność nakładania i też wymaga pozycjonowania innego niż static.

Wartość Co robi
static Domyślne. Element uczestniczy w normalnym przepływie. top/right/bottom/left i z-index nie mają żadnego efektu.
relative Element zostaje w normalnym przepływie, ale możesz go przesunąć względem jego oryginalnej pozycji. Miejsce po nim zostaje zarezerwowane.
absolute Element wyrywa się z przepływu. Pozycjonuje się względem najbliższego przodka z position innym niż static. Jeśli takiego nie ma – względem <html>.
fixed Element wyrywa się z przepływu. Przykleja się do okna przeglądarki i nie rusza przy scrollowaniu.
sticky Zachowuje się jak relative dopóki nie doscrolluje do progu (np. top: 0), potem przykleja się jak fixed – ale tylko w obrębie swojego kontenera.

Domyślna wartość to static. Dopóki nie wpiszesz position, element siedzi w normalnym przepływie i żadne przesunięcia nie działają. position: initial jawnie przywraca tę wartość. position: inherit powoduje dziedziczenie od rodzica – ale normalnie position nie jest dziedziczone.

Właściwość position nie jest dziedziczona. Każdy element domyślnie ma static, nawet jeśli rodzic ma relative czy absolute. Jedynym wyjątkiem jest jawne użycie position: inherit.

Klasyczny układ: kontener z relative + dziecko z absolute:

.karta {

  position: relative;

}



.badge {

  position: absolute;

  top: 8px;

  right: 8px;

}

Przyklejona nawigacja:

nav {

  position: sticky;

  top: 0;

  z-index: 100;

}

Przycisk zawsze w rogu ekranu:

.btn-top {

  position: fixed;

  bottom: 24px;

  right: 24px;

  z-index: 999;

}

Kliknij na dowolny div, żeby go zaznaczyć, a potem zmieniaj jego właściwości. Scrolluj podgląd, żeby zobaczyć działanie sticky i fixed. Kontener podglądu ma position: relative, więc absolute liczy się względem niego.
