Właściwość display: flex włącza na elemencie tryb Flexbox. Sprawia, że dzieci tego elementu (tzw. flex items) układają się w jednym kierunku – domyślnie w rzędzie – i możemy precyzyjnie kontrolować ich rozmiar, kolejność i wyrównanie. To jeden z najczęściej używanych trybów układu w nowoczesnym CSS.

Sam element z display: flex zachowuje się jak blokowy – zajmuje całą szerokość rodzica. Jego dzieci przestają być blokowe i liniowe – stają się elementami flex.

Składnia: display: flex;

Po ustawieniu display: flex na kontenerze masz do dyspozycji zestaw dodatkowych właściwości CSS, które go konfigurują:

Właściwość Przykładowe wartości Co robi
flex-direction row, row-reverse, column, column-reverse Kierunek układania dzieci (oś główna)
flex-wrap nowrap, wrap, wrap-reverse Czy dzieci mogą się zawijać do nowej linii
flex-flow row wrap, column nowrap... Skrót dla flex-direction + flex-wrap
justify-content flex-start, flex-end, center, space-between, space-around, space-evenly Wyrównanie dzieci wzdłuż osi głównej
align-items stretch, flex-start, flex-end, center, baseline Wyrównanie dzieci wzdłuż osi poprzecznej
align-content flex-start, flex-end, center, space-between, space-around, space-evenly, stretch Wyrównanie wierszy gdy jest ich kilka (działa tylko gdy flex-wrap: wrap)
gap px, rem, % Odstęp między dziećmi (row-gap i column-gap razem)
row-gap px, rem, % Odstęp między wierszami
column-gap px, rem, % Odstęp między kolumnami

Na samych dzieciach (flex items) możesz ustawiać:

Właściwość Przykładowe wartości Co robi
flex-grow 0, 1, 2... Jak bardzo element ma się rozciągać żeby wypełnić wolne miejsce
flex-shrink 0, 1, 2... Jak bardzo element ma się kurczyć gdy brakuje miejsca
flex-basis auto, px, %, rem Bazowy rozmiar elementu przed rozciągnięciem/skurczeniem
flex 1, 0 1 auto, 1 1 200px Skrót dla flex-grow + flex-shrink + flex-basis
align-self auto, flex-start, flex-end, center, stretch, baseline Nadpisuje align-items dla konkretnego dziecka
order 0, 1, -1... Kolejność wyświetlania (domyślnie 0)

Domyślna wartość display to block albo inline – zależy od znacznika. Jeśli nie wpiszesz display: flex, dzieci układają się w normalnym przepływie dokumentu.

display: initial przywraca domyślną wartość elementu. display: inherit dziedziczy wartość od rodzica – ale normalnie display nie jest dziedziczone, więc to rzadki przypadek.

Właściwość display nie jest dziedziczona. To że rodzic ma flex nie zmienia display dzieci – one stają się flex items, ale ich własna wartość display nadal decyduje o tym jak układają swoje własne dzieci.

display: inherit wymusza dziedziczenie, ale używa się tego bardzo rzadko. display: initial przywraca domyślną wartość dla danego znacznika.

Wyśrodkowanie elementu w pionie i poziomie – klasyczny przypadek:

.kontener {

  display: flex;

  justify-content: center;

  align-items: center;

  height: 200px;

}

Nawigacja pozioma z równymi odstępami:

nav {

  display: flex;

  justify-content: space-between;

  align-items: center;

  gap: 16px;

}

Karty w rzędzie, które zawijają się gdy nie mieszczą się w jednej linii:

.karty {

  display: flex;

  flex-wrap: wrap;

  gap: 20px;

}



.karta {

  flex: 1 1 200px;

}

Układ kolumnowy – elementy w pionie:

.sidebar {

  display: flex;

  flex-direction: column;

  gap: 8px;

}

Zmieniaj właściwości kontenera i dzieci. Możesz przełączać flex-direction, justify-content, align-items, flex-wrap, gap oraz flex-grow i order na poszczególnych dzieciach.
