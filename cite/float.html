Właściwość float służy do „wypływania” elementu w lewo albo w prawo, żeby tekst lub inne elementy mogły go opływać.

Kiedyś używało się jej do robienia layoutów, ale teraz częściej zastępuje ją flexbox i grid.

Nadal jest przydatna np. do obrazków w tekście.

Ważne! element z tą właściwością traci wysokość!

Składnia: float: wartość;

Wartość Co robi
left ustawia element po lewej stronie
right ustawia element po prawej stronie
none brak „wypływania”, normalny układ
inline-start start strony (zależnie od języka)
inline-end koniec strony (zależnie od języka)

Domyślna wartość to none, czyli element zachowuje się normalnie.

Jeśli ustawimy left lub right, element zaczyna „uciekać” z normalnego układu.

initial resetuje float, a inherit przejmuje od rodzica.

float nie jest dziedziczone automatycznie.

Elementy obok mogą opływać float, co czasem psuje układ strony jeśli nie użyje się clear.

img {
    float: left;
    margin-right: 10px;
}
div {
    float: right;
}

Przykłady użycia:

img {
    float: left;
}
.box {
    float: right;
}
p img {
    float: left;
    margin: 10px;
}
nav {
    float: right;
}

Dzięki temu tekst może „obchodzić” element.
