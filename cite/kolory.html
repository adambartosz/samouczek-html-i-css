Kolory w CSS służą do ustawiania wyglądu elementów, np. tekstu, tła czy obramowania. Najczęściej używa się ich w właściwościach color i background-color.

Kolor można zapisać na kilka sposobów: nazwą, HEX, RGB, RGBA, HSL i HSLA.

To jedna z podstawowych rzeczy przy stylowaniu stron.

Składnia: color: wartość; lub background-color: wartość;

Format Przykład Co robi
nazwa red, blue, green prosty zapis koloru
HEX #ff0000 kolor w systemie szesnastkowym
RGB rgb(255,0,0) kolor z czerwonym, zielonym, niebieskim
RGBA rgba(255,0,0,0.5) jak RGB + przezroczystość
HSL hsl(0,100%,50%) kolor przez odcień, nasycenie i jasność
HSLA hsla(0,100%,50%,0.5) HSL + przezroczystość

Domyślnie tekst ma kolor czarny, czyli color: black.

Tło jest przezroczyste, czyli background-color: transparent.

initial resetuje kolor, a inherit pobiera go od rodzica.

Kolory nie są dziedziczone automatycznie w każdym przypadku, ale color zwykle się dziedziczy.

background-color nie jest dziedziczony.

p {
    color: red;
    background-color: yellow;
}

Przykłady użycia:

h1 {
    color: blue;
}
div {
    background-color: #f0f0f0;
}
button {
    background-color: rgb(0, 150, 0);
    color: white;
}
span {
    color: hsla(200, 100%, 50%, 0.7);
}

Każdy sposób daje trochę inne możliwości stylowania.

Symulator: wybierz kolor i zobacz efekt na elemencie.
