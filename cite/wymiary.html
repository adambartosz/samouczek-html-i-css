Właściwości width oraz height służą do ustawiania szerokości i wysokości elementu w CSS. Dzięki nim kontroluje się rozmiar pudełka w modelu blokowym.

width to szerokość, a height to wysokość elementu. Obie wartości są podstawą przy budowaniu layoutu strony.

Bez nich elementy mają domyślne dopasowanie do treści.

Składnia: właściwość: wartość;

Wartość Co robi
auto automatyczne dopasowanie do treści
px stały rozmiar w pikselach
% procent względem rodzica
vw procent szerokości okna
vh procent wysokości okna
inherit dziedziczenie wartości
initial wartość domyślna

Domyślnie width i height mają wartość auto. Oznacza to, że element sam dopasowuje swój rozmiar.

initial resetuje do domyślnego zachowania przeglądarki, a inherit pobiera wartość od rodzica.

Te właściwości działają na elementach blokowych. Elementy liniowe ignorują height oraz width. 

div {
    width: 200px;
    height: 100px;
}

Dlatego często używa się display: block lub flex.

Przykłady użycia:

.box {
    width: 200px;
    height: 120px;
}
.container {
    width: 80%;
    height: auto;
}
.full {
    width: 100vw;
    height: 100vh;
}

Te ustawienia pozwalają tworzyć responsywne strony.
