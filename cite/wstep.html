Co to jest HTML?

HTML (HyperText Markup Language) to język do tworzenia stron internetowych. Służy do opisywania struktury strony, czyli tego co jest nagłówkiem, tekstem, obrazem albo linkiem.

To nie jest język programowania tylko znaczników. Przeglądarka czyta HTML i na jego podstawie pokazuje stronę.

Do czego służy HTML?

HTML używa się do budowania każdej strony internetowej. Dzięki niemu można tworzyć układ treści.

  • nagłówki i akapity tekstu
  • linki do innych stron
  • obrazy i multimedia
  • listy i tabele
  • formularze do wpisywania danych
  • podział strony na sekcje

Podstawowa struktura strony

Każdy plik HTML ma podobny szkielet. Najważniejsze są elementy <html>, <head> i <body>. 

<!DOCTYPE html>
<html lang="pl">

<head>

<meta charset="utf-8">

<title>Moja strona</title>

</head>

<body>

<h1>Witaj!</h1>

<p>To moja strona HTML</p>

</body>

</html>

Najważniejsze znaczniki

Znacznik Opis
<h1> - <h6> Nagłówki
<p> Akapit tekstu
<a> Link
<img> Obrazek
<div> Kontener blokowy
<span> Kontener liniowy
<ul> Lista punktowana
<ol> Lista numerowana
<table> Tabela

HTML a CSS

HTML odpowiada za strukturę strony, a CSS za wygląd. HTML mówi co jest na stronie, a CSS jak to wygląda.

<p class="tekst">Przykład tekstu</p>
.tekst {
color: blue;
font-size: 18px;
}
