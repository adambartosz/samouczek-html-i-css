Znacznik <svg> jest kontenerem przeznaczonym do umieszczania grafiki wektorowej w dokumencie HTML. Sam nie rysuje żadnych kształtów, ale tworzy obszar roboczy, wewnątrz którego można umieszczać inne elementy SVG.

Grafika SVG skaluje się bez utraty jakości, dlatego często wykorzystuje się ją do ikon, logotypów oraz wykresów. Jest to element kontenerowy posiadający własny układ współrzędnych.

Bez znacznika <svg> nie można używać pozostałych elementów SVG bezpośrednio w kodzie strony.

UWAGA! znaczniki trzeba zamykać w taki sposób: <circle/>, ponieważ wymagana jest '/' na końcu, a inaczej nie zadziała.

Znacznik ten wykorzystuje się, gdy chcemy:

  • utworzyć obszar przeznaczony na grafikę SVG
  • osadzać grafikę wektorową bez używania plików JPG lub PNG
  • tworzyć responsywne ikony i logotypy
  • skalować grafikę bez utraty jakości
  • tworzyć interaktywne elementy graficzne
  • korzystać z innych znaczników SVG, takich jak <circle>, <rect> czy <line>
  • tworzyć animacje SVG

Sam znacznik nie wyświetli żadnego rysunku, dopóki nie zostaną dodane do niego odpowiednie elementy SVG.

Atrybut Wartości Co robi
width liczba, px, %, inne jednostki CSS Określa szerokość obszaru SVG
height liczba, px, %, inne jednostki CSS Określa wysokość obszaru SVG
viewBox min-x min-y szerokość wysokość Definiuje układ współrzędnych grafiki
preserveAspectRatio none, xMinYMin, xMidYMid, xMaxYMax i inne warianty Kontroluje sposób skalowania grafiki
x liczba lub jednostka Pozycja pozioma kontenera SVG
y liczba lub jednostka Pozycja pionowa kontenera SVG

Znacznik <svg> ma znaczenie semantyczne związane z grafiką wektorową. Informuje przeglądarkę, że jego zawartość należy interpretować jako dokument SVG.

Dla wyszukiwarek oraz przeglądarek jest to jasna informacja, że wewnątrz znajduje się grafika wektorowa, a nie zwykła treść HTML.

Właściwość Wartość
Typ elementu Blokowy
Znacznik zamykający Tak (kontenerowy)
Semantyka Kontener grafiki wektorowej SVG
Może zawierać Elementy SVG, definicje, grupy, animacje i opisy
Może być wewnątrz większości elementów HTML przechowujących treść
Domyślny display inline
