Co to jest składnia HTML?

Składnia HTML to zbiór zasad określających sposób zapisywania kodu strony internetowej. Dzięki niej przeglądarka wie, które elementy są nagłówkami, akapitami, obrazami, linkami czy formularzami.

HTML składa się głównie ze znaczników zapisanych w nawiasach ostrych. Większość znaczników posiada część otwierającą i zamykającą.

Przykład prostego znacznika:

<p>To jest akapit.</p>

Przeglądarka wyświetli wtedy zwykły akapit tekstu.

Budowa znacznika HTML

Większość elementów HTML składa się z trzech części:

  • znacznika otwierającego
  • zawartości
  • znacznika zamykającego
<h1>Mój tytuł</h1>
Element Znaczenie
<h1> Znacznik otwierający
Mój tytuł Zawartość elementu
</h1> Znacznik zamykający

Znacznik zamykający różni się od otwierającego ukośnikiem /.

Pełna struktura dokumentu HTML

Każda strona internetowa powinna mieć podstawową strukturę.

<!DOCTYPE html>

<html lang="pl">

<head>

    <meta charset="utf-8">

    <title>Moja strona</title>

</head>

<body>

    <h1>Witaj świecie</h1>

</body>

</html>

Poszczególne elementy mają konkretne zadania:

Element Zastosowanie
DOCTYPE Informuje o użyciu HTML5.
html Główny kontener dokumentu.
head Ustawienia strony.
meta Dodatkowe informacje o dokumencie.
title Tytuł karty przeglądarki.
body Widoczna część strony.

Atrybuty w HTML

Atrybuty przekazują dodatkowe informacje do znaczników.

Umieszcza się je wewnątrz znacznika otwierającego.

<a href="https://google.pl">Google</a>

W tym przykładzie:

  • href jest nazwą atrybutu
  • "https://google.pl" jest jego wartością

Znacznik może mieć więcej niż jeden atrybut.

<img src="obraz.jpg" alt="Zdjęcie" width="300">
Atrybut Przykład
href Adres linku
src Źródło obrazka
alt Opis obrazka
width Szerokość elementu
height Wysokość elementu

Elementy kontenerowe i pojedyncze

W HTML występują dwa podstawowe rodzaje elementów.

Elementy kontenerowe

Posiadają znacznik otwierający i zamykający.

<strong>Pogrubiony tekst</strong>

Przykłady:

  • p
  • div
  • span
  • h1
  • section
  • article
  • strong

Elementy pojedyncze

Nie posiadają znacznika zamykającego.

<br>
<img src="foto.jpg" alt="Zdjęcie">

Przykłady:

  • br
  • img
  • hr
  • meta
  • link
  • input

Zagnieżdżanie elementów

Elementy HTML można umieszczać wewnątrz innych elementów.

<p>

To jest <strong>ważny</strong> tekst.

</p>

Ważne jest zachowanie poprawnej kolejności zamykania znaczników.

Poprawnie:

<p><strong>Tekst</strong></p>

Niepoprawnie:

<p><strong>Tekst</p></strong>

Znacznik otwarty jako ostatni powinien zostać zamknięty jako pierwszy.

Wcięcia i czytelność kodu

Przeglądarka nie wymaga wcięć, ale programiści stosują je dla czytelności.

Czytelny kod:

<body>

    <header>

        <h1>Strona</h1>

    </header>

</body>

Nieczytelny kod:

<body><header><h1>Strona</h1></header></body>

Przy większych projektach odpowiednie formatowanie kodu bardzo ułatwia pracę.

Najczęstsze błędy początkujących

  • brak znacznika zamykającego
  • literówki w nazwach znaczników
  • niepoprawne zagnieżdżanie elementów
  • brak atrybutu alt przy obrazach
  • pomijanie DOCTYPE
  • umieszczanie elementów body wewnątrz head
  • powtarzanie tych samych identyfikatorów id
  • zapominanie o cudzysłowach przy atrybutach

Większość takich błędów można wykryć przy pomocy walidatora HTML.

Drzewo dokumentu HTML

Przeglądarka traktuje stronę jak strukturę drzewa.

html

├── head

│   ├── meta

│   └── title

└── body

    ├── header

    │   └── h1

    ├── main

    │   ├── section

    │   └── article

    └── footer

Takie drzewo jest później zamieniane na model DOM wykorzystywany przez JavaScript.
