Co to są animacje CSS?

CSS daje dwa sposoby na ożywienie elementów: transition i animation. Transition to płynne przejście między dwoma stanami – np. zmiana koloru przy hoverze. Animation to pełnoprawna animacja z klatkami kluczowymi, która może się zapętlać i działać bez interakcji użytkownika.

Obie właściwości działają bez JavaScriptu – przeglądarka sama oblicza pośrednie klatki.

Transition

Składnia:

transition: właściwość czas funkcja opóźnienie;
button {

  background: #333;

  transition: background 0.3s ease;

}



button:hover {

  background: #0066cc;

}

Parametry transition:

  • właściwość – co animować: background, color, transform, opacity, all itp.
  • czas – jak długo trwa przejście, np. 0.3s, 200ms
  • funkcja – krzywa przyspieszenia (patrz niżej)
  • opóźnienie – ile czekać przed startem, np. 0.1s

Można animować kilka właściwości jednocześnie:

transition: background 0.3s ease, transform 0.2s ease, opacity 0.3s;

Nie wszystkie właściwości CSS da się animować. Działają te, które mają wartości numeryczne – kolory, rozmiary, pozycje, opacity, transform. Nie działają np. display ani font-family.

Funkcje czasowe (timing functions)

Funkcja czasowa określa jak zmienia się prędkość animacji w czasie:

  • linear – stała prędkość przez cały czas
  • ease – wolno, potem szybko, potem wolno (domyślna)
  • ease-in – zaczyna wolno, przyspiesza
  • ease-out – zaczyna szybko, zwalnia
  • ease-in-out – wolno na starcie i końcu, szybko w środku
  • cubic-bezier(x1, y1, x2, y2) – własna krzywa Béziera, pełna kontrola
  • steps(n) – animacja skokowa, n kroków bez płynnego przejścia

Animation i @keyframes

Animacja działa bez interakcji – wystarczy załadowanie strony. Definiujesz ją w dwóch miejscach: @keyframes opisuje co się dzieje w kolejnych momentach, a właściwość animation przypisuje ją do elementu:

@keyframes wskok {

  0%   { transform: translateY(-30px); opacity: 0; }

  100% { transform: translateY(0);     opacity: 1; }

}



.box {

  animation: wskok 0.5s ease-out forwards;

}

Parametry animation:

  • nazwa – nazwa z @keyframes
  • czas trwania – np. 1s, 400ms
  • funkcja czasowa – tak samo jak w transition
  • opóźnienie – np. 0.2s
  • liczba powtórzeń – liczba lub infinite
  • kierunek – normal, reverse, alternate, alternate-reverse
  • fill-mode – forwards (zostań na końcowej klatce), backwards, both, none
  • play-state – running lub paused
@keyframes obrót {

  from { transform: rotate(0deg); }

  to   { transform: rotate(360deg); }

}



.loader {

  animation: obrót 1s linear infinite;

}

Klatki kluczowe można definiować przez from/to albo przez procenty – możesz mieć tyle klatek ile chcesz:

@keyframes puls {

  0%   { transform: scale(1); }

  50%  { transform: scale(1.15); }

  100% { transform: scale(1); }

}

Kierunek animacji (animation-direction)

Kierunek decyduje w którą stronę odtwarzana jest animacja i jak zachowuje się przy kolejnych powtórzeniach:

  • normal – od 0% do 100%, za każdym razem od początku (domyślny)
  • reverse – od 100% do 0%, animacja odtwarzana wspak
  • alternate – pierwsze powtórzenie normalnie (0%→100%), drugie wspak (100%→0%), trzecie normalnie itd. Przydatne do efektu wahadła
  • alternate-reverse – jak alternate, ale zaczyna od wspak (100%→0%)
.wahadlo {

  animation: ruch 1s ease-in-out infinite alternate;

}

Transform

Właściwość transform to najczęściej animowana rzecz w CSS, bo nie powoduje przeliczania layoutu (jest wydajna). Funkcje transform:

  • translateX(px), translateY(px), translate(x, y) – przesunięcie
  • scaleX(n), scaleY(n), scale(n) – skalowanie, gdzie 1 = normalny rozmiar
  • rotate(deg) – obrót w stopniach
  • skewX(deg), skewY(deg) – pochylenie
  • translateZ(px), rotateX(deg), rotateY(deg) – efekty 3D (potrzeba perspective na rodzicu)

Można łączyć kilka funkcji naraz:

transform: translateY(-4px) scale(1.05);

Punkt, względem którego działa transform, ustawia transform-origin (domyślnie środek elementu): 

transform-origin: top left;

transform-origin: 50% 100%;
