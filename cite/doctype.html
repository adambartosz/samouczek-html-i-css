Co to jest DOCTYPE?

DOCTYPE (Document Type Declaration) to deklaracja umieszczana na samym początku dokumentu HTML. Informuje przeglądarkę, jakiego standardu HTML używa dana strona.

Nie jest to zwykły znacznik HTML. Nie posiada znacznika zamykającego i nie wyświetla żadnej treści na stronie.

Współcześnie praktycznie wszystkie strony internetowe korzystają z deklaracji HTML5:

<!DOCTYPE html>

Deklaracja ta powinna znajdować się jako pierwszy element dokumentu, jeszcze przed znacznikiem <html>.

Po co używa się DOCTYPE?

Głównym zadaniem DOCTYPE jest poinformowanie przeglądarki, że kod powinien być interpretowany zgodnie z określonym standardem.

  • włącza standardowy tryb renderowania strony
  • zapobiega przejściu przeglądarki w tryb zgodności ze starymi stronami
  • pomaga poprawnie interpretować HTML i CSS
  • zwiększa zgodność między różnymi przeglądarkami
  • jest wymagany przez walidatory HTML
  • ułatwia tworzenie nowoczesnych stron internetowych

Brak deklaracji może powodować nieprzewidywalne zachowanie układu strony.

Gdzie umieszcza się DOCTYPE?

Poprawna struktura dokumentu HTML wygląda następująco:

<!DOCTYPE html>

<html lang="pl">

<head>

    <meta charset="utf-8">

    <title>Moja strona</title>

</head>

<body>

    Treść strony

</body>

</html>

DOCTYPE zawsze znajduje się na pierwszej linii pliku HTML.

Nie należy umieszczać przed nim:

  • spacji
  • komentarzy HTML
  • znaczników HTML
  • skryptów JavaScript
  • deklaracji CSS

Tryb standardowy i tryb zgodności

Przeglądarki mogą interpretować stronę na dwa sposoby:

Tryb Opis
Standards Mode Przeglądarka stosuje aktualne standardy HTML i CSS.
Quirks Mode Przeglądarka próbuje zachowywać się jak bardzo stare wersje programów do przeglądania stron.

Nowoczesny DOCTYPE HTML5 powoduje uruchomienie trybu standardowego.

Dzięki temu układ strony działa przewidywalnie w różnych przeglądarkach.

Starsze deklaracje DOCTYPE

Przed pojawieniem się HTML5 deklaracje były znacznie bardziej rozbudowane.

Przykład HTML 4.01 Transitional:

<!DOCTYPE HTML PUBLIC
"-//W3C//DTD HTML 4.01 Transitional//EN"
"http://www.w3.org/TR/html4/loose.dtd">

Przykład XHTML 1.0 Strict:

<!DOCTYPE html PUBLIC
"-//W3C//DTD XHTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

HTML5 znacząco uprościł zapis:

<!DOCTYPE html>

Dzięki temu kod jest krótszy, czytelniejszy i łatwiejszy do zapamiętania.
