Czym są typy stylów?

W CSS istnieją trzy podstawowe sposoby dodawania stylów do strony internetowej. Różnią się one miejscem zapisu kodu CSS oraz wygodą użycia.

Każdy z tych sposobów powoduje ten sam efekt wizualny, ale w praktyce najczęściej korzysta się z zewnętrznych arkuszy stylów.

Styl lokalny (inline)

Styl lokalny zapisuje się bezpośrednio w znaczniku HTML za pomocą atrybutu style.

<p style="color:red;">Przykładowy tekst</p>

Zalety:

  • szybkie dodanie pojedynczego stylu
  • proste do przetestowania

Wady:

  • utrudnia zarządzanie większym projektem
  • powoduje mieszanie HTML i CSS
  • trudno zmieniać wygląd wielu elementów naraz

Styl wewnętrzny (internal)

Styl wewnętrzny zapisuje się w znaczniku <style> znajdującym się najczęściej w sekcji <head>. 

<head>

    <style>

        p {

            color: blue;

        }

    </style>

</head>

Zalety:

  • oddzielenie stylów od treści HTML
  • wygodne przy małych stronach
  • łatwa edycja wszystkich reguł w jednym miejscu

Wady:

  • style działają tylko w jednym dokumencie
  • przy dużych projektach plik HTML staje się zbyt długi

Zewnętrzny arkusz stylów (external)

Jest to najczęściej używany sposób dodawania CSS. Style zapisuje się w osobnym pliku z rozszerzeniem .css.

Podłączenie arkusza:

<link rel="stylesheet" href="style.css">

Przykładowa zawartość pliku CSS:

body {

    font-family: Arial, sans-serif;

}



h1 {

    color: green;

}

Zalety:

  • jeden plik może obsługiwać wiele stron
  • łatwe zarządzanie projektem
  • czytelniejszy kod HTML
  • szybsze ładowanie kolejnych podstron dzięki pamięci podręcznej przeglądarki

Wady:

  • wymaga dodatkowego pliku

Porównanie typów stylów

Typ stylu Miejsce zapisu Zastosowanie
lokalny Atrybut style Pojedyncze elementy
Wewnętrzny Znacznik style Małe strony i testy
Zewnętrzny Osobny plik CSS Profesjonalne projekty

Który typ stylów wybrać?

W prawdziwych projektach zdecydowanie najczęściej stosuje się zewnętrzne arkusze stylów. Dzięki nim kod HTML pozostaje przejrzysty, a zmiany wyglądu można wykonywać w jednym miejscu.

Styl wewnętrzny sprawdza się podczas nauki lub przy bardzo małych stronach. Styl lokalny warto traktować głównie jako rozwiązanie pomocnicze do szybkich testów.

Najlepsza praktyka:

  1. używaj zewnętrznego pliku CSS
  2. ograniczaj style wewnętrzne
  3. unikaj stylów lokalnych, jeśli nie są konieczne
