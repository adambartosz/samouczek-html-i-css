Co to jest hierarchia selektorów?

Hierarchia selektorów określa relacje pomiędzy elementami HTML. Dzięki niej można wybierać elementy znajdujące się wewnątrz innych elementów.

Takie selektory są nazywane selektorami złożonymi lub relacyjnymi. Pozwalają bardzo dokładnie wskazać, które elementy mają zostać ostylowane.

Zamiast wybierać wszystkie elementy danego typu, można wybrać tylko te znajdujące się w określonym miejscu dokumentu.

Selektor potomka

Selektor potomka wybiera wszystkie elementy znajdujące się wewnątrz innego elementu, niezależnie od poziomu zagnieżdżenia.

div p {

    color: blue;

}

Przeglądarka wybierze wszystkie akapity znajdujące się gdziekolwiek wewnątrz elementu div.

Przykład HTML:

<div>

    <section>

        <p>Tekst</p>

    </section>

</div>

Akapit zostanie zaznaczony, mimo że nie jest bezpośrednim dzieckiem elementu div.

Selektor dziecka

Selektor dziecka wybiera tylko elementy znajdujące się bezpośrednio wewnątrz wskazanego rodzica.

div > p {

    color: red;

}

Zostaną wybrane wyłącznie akapity będące bezpośrednimi dziećmi elementu div.

Przykład:

<div>

    <p>Pasuje</p>

    <section>

        <p>Nie pasuje</p>

    </section>

</div>

Wybrany zostanie tylko pierwszy akapit.

Selektor sąsiedniego rodzeństwa

Selektor + wybiera pierwszy element znajdujący się bezpośrednio po innym elemencie.

h2 + p {

    font-weight: bold;

}

Wybrany zostanie pierwszy akapit występujący zaraz po nagłówku h2.

Przykład:

<h2>Tytuł</h2>

<p>Pasuje</p>

<p>Nie pasuje</p>

Tylko pierwszy akapit otrzyma styl.

Selektor ogólnego rodzeństwa

Selektor ~ wybiera wszystkie elementy znajdujące się później na tym samym poziomie zagnieżdżenia.

h2 ~ p {

    color: green;

}

Wybrane zostaną wszystkie akapity znajdujące się po nagłówku h2.

Przykład:

<h2>Tytuł</h2>

<p>Pasuje</p>

<p>Pasuje</p>

<div></div>

<p>Pasuje</p>

Każdy akapit znajdujący się po nagłówku zostanie wybrany.

Porównanie selektorów hierarchicznych

Selektor Przykład Działanie
Potomek div p Wszystkie akapity wewnątrz div
Dziecko div > p Tylko bezpośrednie dzieci
Sąsiednie rodzeństwo h2 + p Pierwszy element po wskazanym
Ogólne rodzeństwo h2 ~ p Wszystkie późniejsze elementy tego samego poziomu

Drzewo dokumentu HTML

Hierarchię elementów można traktować jak drzewo.

body

├── div

│   ├── h2

│   └── p

└── section

    └── p

W takim układzie:

  • body jest rodzicem dla div i section
  • div jest rodzicem dla h2 i p
  • h2 i p są rodzeństwem
  • wszystkie elementy są potomkami body

Kiedy stosować poszczególne selektory?

  • div p gdy interesują nas wszystkie potomki
  • div > p gdy interesują nas tylko bezpośrednie dzieci
  • h2 + p gdy chcemy ostylować pierwszy element po nagłówku
  • h2 ~ p gdy chcemy ostylować wszystkie kolejne elementy tego samego poziomu

Dzięki tym selektorom można pisać bardziej precyzyjny i krótszy kod CSS.
