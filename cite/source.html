Znacznik <source> służy do definiowania źródeł danych dla elementów multimedialnych. Najczęściej używa się go wewnątrz znaczników <audio>, <video> oraz <picture>.

Jest elementem pustym, czyli nie posiada znacznika zamykającego i nie zawiera własnej treści. Przeglądarka analizuje kolejne źródła i wybiera pierwsze, które potrafi obsłużyć.

Dzięki temu można przygotować kilka wersji tego samego pliku i zwiększyć zgodność strony z różnymi urządzeniami oraz przeglądarkami.

Najczęstsze zastosowania znacznika:

  • podawanie kilku formatów plików audio dla znacznika <audio>
  • podawanie kilku formatów plików wideo dla znacznika <video>
  • tworzenie responsywnych obrazów z użyciem <picture>
  • dostosowywanie obrazów do szerokości ekranu
  • dostarczanie nowoczesnych formatów grafik, takich jak WebP
  • zwiększanie kompatybilności multimediów pomiędzy przeglądarkami

Jeżeli wystarcza tylko jeden plik multimedialny, można użyć bezpośrednio atrybutu src w znaczniku <audio> lub <video>.

Atrybut Wartości Co robi
src URL lub ścieżka do pliku Wskazuje źródło danych
type typ MIME, np. audio/mpeg, video/mp4, image/webp Określa typ pliku
media media query CSS Pozwala użyć źródła tylko przy określonych warunkach
srcset lista obrazów i rozdzielczości Definiuje alternatywne wersje obrazu

Znacznik <source> ma znaczenie semantyczne związane z multimediami. Informuje przeglądarkę, że zawiera alternatywne źródło pliku dla elementu nadrzędnego.

Samodzielnie nie wyświetla żadnej treści użytkownikowi. Jego zadaniem jest dostarczenie informacji potrzebnych do poprawnego wyboru pliku przez przeglądarkę.

Czytniki ekranu nie odczytują znacznika bezpośrednio, ponieważ jest on elementem technicznym wykorzystywanym przez inne znaczniki.

Właściwość Wartość
Typ elementu Pusty
Znacznik zamykający Nie (niekontenerowy)
Semantyka Źródło danych dla audio, video lub picture
Może zawierać Żadnych elementów
Może być wewnątrz audio, video, picture
Domyślny display none
