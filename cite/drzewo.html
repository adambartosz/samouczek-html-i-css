Co oznaczają rodzice, dzieci i wnukowie?

W HTML elementy są połączone ze sobą w strukturę przypominającą drzewo. Dlatego często używa się określeń rodzic, dziecko oraz wnuk.

Dzięki temu łatwiej zrozumieć budowę strony, działanie CSS oraz JavaScript.

Relacje te wynikają z zagnieżdżania elementów wewnątrz innych elementów.

Element rodzic

Rodzicem nazywamy element, który zawiera w sobie inne elementy.

<div>

    <p>Tekst</p>

</div>

W tym przykładzie:

  • <div> jest rodzicem
  • <p> jest dzieckiem

Jeden rodzic może mieć wiele dzieci.

Element dziecko

Dzieckiem nazywamy element znajdujący się bezpośrednio wewnątrz rodzica.

<section>

    <h1>Tytuł</h1>

    <p>Treść</p>

</section>

W tym przypadku:

  • <section> jest rodzicem
  • <h1> jest dzieckiem
  • <p> jest dzieckiem

Oba elementy znajdują się dokładnie jeden poziom niżej od rodzica.

Element wnuk

Wnuk to element znajdujący się wewnątrz dziecka.

<div>

    <section>

        <p>Tekst</p>

    </section>

</div>

Relacje wyglądają następująco:

  • <div> - rodzic
  • <section> - dziecko
  • <p> - wnuk

Element <p> nie jest bezpośrednim dzieckiem elementu <div>, ponieważ pomiędzy nimi znajduje się jeszcze <section>.

Przykład drzewa HTML

Poniższy kod tworzy prostą strukturę dokumentu.

<body>

    <header>

        <h1>Tytuł</h1>

    </header>



    <main>

        <section>

            <p>Treść</p>

        </section>

    </main>

</body>

Drzewo tego dokumentu:

body

├── header

│   └── h1

└── main

    └── section

        └── p

Rodzeństwo elementów

Jeżeli dwa elementy mają tego samego rodzica, są względem siebie rodzeństwem.

<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>

W tym przykładzie wszystkie znaczniki <li> są rodzeństwem, ponieważ mają wspólnego rodzica <ul>.

Dlaczego jest to ważne?

Znajomość tych relacji jest bardzo ważna podczas pisania CSS.

Przykład selektora wybierającego dzieci:

div > p {

    color: red;

}

Powyższy zapis wybierze tylko akapity będące bezpośrednimi dziećmi elementu div.

Relacje rodzinne są również wykorzystywane w JavaScript podczas poruszania się po strukturze DOM.

Najczęściej używane relacje DOM w JavaScript

Właściwość Znaczenie
parentElement Pobiera rodzica elementu.
children Pobiera wszystkie dzieci.
firstElementChild Pierwsze dziecko.
lastElementChild Ostatnie dziecko.
nextElementSibling Następne rodzeństwo.
previousElementSibling Poprzednie rodzeństwo.
