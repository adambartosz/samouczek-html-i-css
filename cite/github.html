Co to jest GitHub?

GitHub to internetowa platforma służąca do przechowywania kodu źródłowego oraz współpracy nad projektami programistycznymi. Opiera się na systemie kontroli wersji Git, dzięki któremu można śledzić zmiany w plikach, przywracać starsze wersje oraz pracować zespołowo.

GitHub jest używany zarówno przez pojedynczych programistów, jak i duże firmy. Pozwala przechowywać projekty publiczne oraz prywatne, a także zarządzać zadaniami, błędami i dokumentacją.

Dla ucznia technikum programistycznego GitHub jest jednym z najważniejszych narzędzi, ponieważ większość współczesnych projektów programistycznych korzysta z repozytoriów Git.

Podstawowe pojęcia

Pojęcie Znaczenie
Git System kontroli wersji działający lokalnie na komputerze.
GitHub Serwis internetowy przechowujący repozytoria Git.
Repozytorium Miejsce przechowywania projektu i jego historii zmian.
Commit Zapis zmian wykonanych w projekcie.
Branch Oddzielna gałąź rozwoju projektu.
Merge Połączenie zmian z różnych gałęzi.
Push Wysłanie zmian na GitHub.
Pull Pobranie zmian z repozytorium.
Fork Kopia cudzego repozytorium na własnym koncie.
Pull Request Propozycja wprowadzenia zmian do projektu.
Issue Zgłoszenie błędu lub zadania.
README Plik opisujący projekt.

Dlaczego warto używać GitHuba?

  • umożliwia bezpieczne przechowywanie kodu
  • pozwala śledzić historię zmian
  • ułatwia współpracę wielu programistów
  • umożliwia przywrócenie wcześniejszych wersji projektu
  • jest standardem w branży IT
  • pozwala budować portfolio projektów
  • ułatwia naukę programowania zespołowego
  • integruje się z wieloma narzędziami programistycznymi
  • umożliwia automatyzację procesów przez GitHub Actions
  • pozwala publikować strony internetowe przez GitHub Pages

Wielu pracodawców sprawdza profile GitHub kandydatów. Aktywność na platformie może być dodatkowym atutem podczas szukania praktyk lub pierwszej pracy.
