Właściwość display: grid włącza na elemencie tryb siatki. Dzieci kontenera rozmieszczają się w dwuwymiarowym układzie kolumn i wierszy, który sam definiujesz. W przeciwieństwie do Flexboxa, Grid działa jednocześnie w obu kierunkach – poziomym i pionowym.

Sam element z display: grid zachowuje się jak blokowy. Jego dzieci stają się elementami siatki i można je precyzyjnie umieszczać w konkretnych komórkach lub rozciągać na wiele kolumn i wierszy.

Składnia: display: grid;

Po ustawieniu display: grid konfigurujesz siatkę właściwościami na kontenerze:

Właściwość Przykładowe wartości Co robi
grid-template-columns 200px 1fr, repeat(3, 1fr), auto 1fr 2fr Definiuje liczbę i szerokości kolumn siatki
grid-template-rows 100px auto, repeat(2, 150px) Definiuje liczbę i wysokości wierszy siatki
grid-template-areas "header header" "nav main" Nazywa obszary siatki – przypisujesz je dzieciom przez grid-area
grid-template 100px / 1fr 2fr Skrót dla grid-template-rows / grid-template-columns
grid-auto-columns px, fr, auto, minmax() Rozmiar kolumn tworzonych automatycznie, poza zdefiniowaną siatką
grid-auto-rows px, fr, auto, minmax() Rozmiar wierszy tworzonych automatycznie
grid-auto-flow row, column, row dense, column dense Kierunek automatycznego umieszczania elementów. dense wypełnia luki
gap 8px, 1rem Odstęp między komórkami – skrót dla row-gap i column-gap
row-gap px, rem, % Odstęp tylko między wierszami
column-gap px, rem, % Odstęp tylko między kolumnami
justify-items start, end, center, stretch Wyrównanie dzieci w poziomie wewnątrz ich komórek
align-items start, end, center, stretch, baseline Wyrównanie dzieci w pionie wewnątrz ich komórek
justify-content start, end, center, space-between, space-around, space-evenly Wyrównanie całej siatki w poziomie wewnątrz kontenera (gdy siatka jest węższa niż kontener)
align-content start, end, center, space-between, space-around, space-evenly, stretch Wyrównanie całej siatki w pionie wewnątrz kontenera

Na samych dzieciach (grid items) możesz ustawiać:

Właściwość Przykładowe wartości Co robi
grid-column 1 / 3, 2 / span 2, 1 / -1 Skrót dla grid-column-start / grid-column-end
grid-row 1 / 3, 2 / span 2 Skrót dla grid-row-start / grid-row-end
grid-column-start 1, 2, span 2 Linia startowa kolumny (linie numerowane od 1)
grid-column-end 3, -1, span 3 Linia końcowa kolumny. -1 = ostatnia linia. span N = rozciągnij przez N kolumn
grid-row-start 1, 2, span 2 Linia startowa wiersza
grid-row-end 3, -1, span 2 Linia końcowa wiersza
grid-area header, nav, main Przypisuje element do nazwanego obszaru z grid-template-areas
justify-self start, end, center, stretch Nadpisuje justify-items dla konkretnego dziecka
align-self start, end, center, stretch, baseline Nadpisuje align-items dla konkretnego dziecka
order 0, 1, -1 Kolejność wyświetlania w automatycznym przepływie

Jednostka fr (fraction) oznacza ułamek dostępnej wolnej przestrzeni. repeat(3, 1fr) to skrót dla 1fr 1fr 1fr.

Funkcja minmax(min, max) definiuje zakres rozmiaru kolumny lub wiersza. Kolumna nie będzie węższa niż min i nie szersza niż max. Możesz mieszać jednostki:

Przykład Co oznacza
minmax(100px, 1fr) Minimum 100px, ale rośnie proporcjonalnie do wolnego miejsca
minmax(200px, auto) Minimum 200px, ale może rosnąć gdy treść jest szersza
minmax(0, 1fr) Może się skurczyć do 0, ale proporcjonalnie zajmuje wolne miejsce – używane gdy 1fr powoduje przepełnienie
minmax(auto, 300px) Minimum = rozmiar treści, maksimum 300px

Klasyczny wzorzec responsywnej siatki bez media queries: repeat(auto-fit, minmax(200px, 1fr)) – tworzy tyle kolumn ile się mieści, każda minimum 200px.

auto-fit vs auto-fill: oba automatycznie tworzą kolumny. Różnią się gdy elementów jest mniej niż kolumn – auto-fit zwija puste kolumny i rozciąga istniejące, auto-fill zostawia puste miejsca.

Domyślna wartość display to block albo inline zależnie od znacznika. Jeśli nie wpiszesz display: grid, dzieci układają się w normalnym przepływie.

display: initial przywraca domyślną wartość elementu. display: inherit dziedziczy po rodzicu – ale normalnie display nie jest dziedziczone.

Właściwość display nie jest dziedziczona. To że rodzic ma grid nie zmienia display dzieci – stają się grid items, ale ich własne dzieci układają się już normalnie (chyba że im też ustawisz display: grid).

display: inherit wymusza dziedziczenie, ale używa się tego bardzo rzadko. display: initial przywraca domyślną wartość dla danego znacznika.

Trzy równe kolumny:

.siatka {

  display: grid;

  grid-template-columns: repeat(3, 1fr);

  gap: 16px;

}

Klasyczny layout strony z nazwanymi obszarami:

.strona {

  display: grid;

  grid-template-columns: 200px 1fr;

  grid-template-rows: auto 1fr auto;

  grid-template-areas:

    "header header"

    "nav    main"

    "footer footer";

  gap: 12px;

}



header { grid-area: header; }

nav    { grid-area: nav; }

main   { grid-area: main; }

footer { grid-area: footer; }

Element rozciągnięty na całą szerokość siatki:

.baner {

  grid-column: 1 / -1;

}

Responsywna siatka kart bez media queries:

.karty {

  display: grid;

  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

  gap: 20px;

}

Konfiguruj siatkę i właściwości poszczególnych dzieci. Kliknij na element żeby go zaznaczyć i zmienić jego grid-column, grid-row oraz align-self.
